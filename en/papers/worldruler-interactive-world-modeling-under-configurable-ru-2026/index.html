Deep Analysis

Innovations

  • Proposes WorldRuler, an interactive world model that follows user-defined rules beyond real-world behaviors.
  • Organizes rule definitions, dependencies, and object states in an executable 3D rule graph.
  • Connects rule execution, video generation, and perceptual feedback in a closed loop.
  • Supports joint saving and restoration of rules and world states to maintain Rule-State Persistence.
  • Introduces dynamic object binding to ground rule-specified entities in visual instances and constrain generation from stored states.
  • Introduces object attribute state replacement and counterfactual reconstruction training for accurate attribute control and compatible appearance and motion changes.
  • Develops an automated data collection and annotation pipeline using GTA-V and Habitat to construct the RuleVerse dataset with detailed state and event annotations.

Methodology

WorldRuler represents rule definitions, dependencies, and object states in an executable 3D rule graph and links rule execution, video generation, and perceptual feedback in a closed loop. The model uses dynamic object binding to ground rule-specified entities in visual instances and stored states to constrain generation from first appearance. It also employs object attribute state replacement and counterfactual reconstruction training, with an automated GTA-V and Habitat pipeline constructing the RuleVerse dataset.

Key Results

Extensive experiments demonstrate that WorldRuler is effective in preserving rule-state consistency across saving and loading and accurately realizing rule outcomes on designated objects and attributes.

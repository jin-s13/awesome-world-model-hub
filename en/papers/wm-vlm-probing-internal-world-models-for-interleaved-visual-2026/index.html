WM-VLM: Probing Internal World Models for Interleaved Visual-Textual Reasoning

arXiv 2026 37.8 method

TLDR

Introduces WM-VLM, adding a lightweight world model branch to VLMs to generate intermediate visual states, improving 2D/3D mental rotation reasoning by up to 39.25 points.

Reasoning

Strengths include a clear two-stage training procedure, programmatically verifiable spatial tasks, strong gains over supervised fine-tuning, and ablations showing dependence on generated visual states. Weaknesses are that evaluations use synthetic mental rotation tasks rather than real-world benchmarks, and the world model scope is limited to next-state generation for spatial reasoning, not broader dynamics.

Deep Analysis

Innovations

  • Introduces WM-VLM, equipping a pretrained VLM with a lightweight world model branch for generating intermediate visual states.
  • Uses a two-stage training process: first learn to generate the next visual state, then learn to reason using that generated state.
  • Constructs programmatic spatial reasoning tasks with verifiable intermediate visual states to evaluate both generation quality and reliance on visual states.
  • Demonstrates that generated visual states improve spatial reasoning compared with a language-only supervised fine-tuned VLM.

Methodology

WM-VLM adds a lightweight world model branch to a pretrained VLM to generate intermediate visual states. The model is trained in two stages: first to generate the next visual state, then to use that state for reasoning. Evaluation uses programmatically constructed 2D and 3D mental rotation tasks with verifiable intermediate visual states, comparing against a supervised fine-tuned backbone and ablating the generated states.

Key Results

WM-VLM consistently outperforms the supervised fine-tuned backbone on 2D and 3D mental rotation tasks, with improvements up to 39.25 percentage points. Ablations show that removing or corrupting the generated visual states sharply reduces performance.

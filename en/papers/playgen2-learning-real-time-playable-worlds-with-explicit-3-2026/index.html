Deep Analysis

Innovations

  • Separates learned 3D state evolution from neural rendering instead of using generated frames as the sole recurrent world representation.
  • Maintains a persistent world memory with static geometry as a volumetric occupancy grid and identity-indexed 3D states for the player and other entities.
  • Jointly learns action-conditioned entity dynamics, geometry completion, and entity discovery within a fixed-size local region.
  • Neural renderer synthesizes first-person observations from depth and semantic projections of the world state without feeding generated images back into state prediction.
  • Demonstrates zero-shot deployment on unseen Doom maps, multiplayer interaction via composition of single-player models, and programmable gameplay through rule-based state interventions.
  • Achieves real-time efficiency with approximately 160ms backend latency on a MacBook Pro with an M4 Pro chip.

Methodology

PlayGen2 maintains a persistent world memory consisting of a volumetric occupancy grid for static geometry and identity-indexed 3D states for the player and entities. A world-state model jointly learns action-conditioned entity dynamics, geometry completion, and entity discovery within a fixed-size local region, while a separate neural renderer synthesizes first-person observations from depth and semantic projections of the world state. The approach is evaluated using Doom as a testbed, with experiments on unseen maps, multiplayer composition, and rule-based interventions.

Key Results

Using Doom, PlayGen2 successfully learns geometry-aware player motion and player-NPC interactions, and the full simulation and rendering pipeline runs at approximately 160ms backend latency on a MacBook Pro with an M4 Pro chip. It also demonstrates zero-shot deployment on unseen Doom maps, multiplayer interaction through composition of single-player models, and programmable gameplay via rule-based state interventions.

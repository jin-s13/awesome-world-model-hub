Deep Analysis

Innovations

  • LLM coding agent acts as a teleoperator: given a data request and one calibration episode, it rebuilds the target task in simulation by writing the scene, an expert controller, and a success judge.
  • A video model conditioned on real images renders simulated rollouts as photographic video with all camera views generated together consistently.
  • DataFarm outputs real-ready data: synchronized camera views labeled with robot actions, enabling direct policy training and real-robot deployment.
  • Independent judges certify the expert and every rendered episode before data admission.
  • Cost-efficient automation: task adaptation costs about $21 in API usage plus a $5 render contract, and additional episodes average $0.80, with no robot or operator time required.

Methodology

The DataFarm agent receives a data request and one calibration episode of the robot in the target scene, then writes a simulation scene, expert controller, and success judge. The simulator provides exact actions, and a video model conditioned on real images renders photorealistic multi-view videos. Policies are trained on farm data or teleoperated episodes and evaluated on five real-robot tasks over 100 trials, including generalization tests and cost comparisons.

Key Results

Policies trained only on farm data match policies trained on the same number of teleoperated episodes, achieving 93 versus 84 successes in 100 trials, and under an unseen tablecloth and colored light they retain 87 successes while teleoperation-trained policies fall to 46. One hour of three-view data costs about $107 on average, compared with $117 for teleoperation in China and $290 in North America labor alone.

Deep Analysis

Innovations

  • DeltaTok tokenizer encodes VFM feature differences between consecutive frames into a single continuous delta token
  • DeltaWorld generative world model operates on delta tokens to efficiently generate diverse plausible futures
  • Delta tokens reduce video from 3D spatio-temporal representation to 1D temporal sequence, e.g., 1,024x token reduction for 512x512 frames
  • Enables tractable multi-hypothesis training by generating many futures in parallel and supervising only the best
  • At inference, produces diverse predictions in a single forward pass

Methodology

The method predicts futures in the feature space of a vision foundation model. DeltaTok encodes VFM feature differences between consecutive frames into single continuous delta tokens, and DeltaWorld is a generative world model trained on these tokens. Training uses multi-hypothesis supervision where many futures are generated in parallel and only the best is supervised, with evaluation on dense forecasting tasks.

Key Results

On dense forecasting tasks, DeltaWorld forecasts futures that more closely align with real-world outcomes while having over 35x fewer parameters and using 2,000x fewer FLOPs than existing generative world models.

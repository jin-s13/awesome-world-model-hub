TLDR

Introduces MoReGen, a physics-grounded text-to-video framework using multi-agent LLMs and simulators, plus MoReSet benchmark to evaluate physical validity via object-trajectory correspondence.

Reasoning

The paper addresses an important gap by benchmarking physical validity in T2V generation and proposing a code-based framework with explicit physics simulation.

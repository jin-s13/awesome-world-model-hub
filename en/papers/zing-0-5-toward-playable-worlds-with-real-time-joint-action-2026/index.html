Deep Analysis

Innovations

  • Unified action and text conditioning combining magnitude-aware keyboard inputs with temporally aligned text instructions and jointly annotated videos to learn navigation and event control within the same sequence.
  • Event-scale supervision for incremental generation using a segment-level teacher trained on connected multi-prompt videos to supervise a block-level causal student through distribution-matching distillation.
  • Low-cost real-time interaction combining four-step generation with context-preserving streaming to support 832 x 480 inference at 24 FPS at approximately USD 0.009 per stream-minute.

Methodology

Zing-0.5 is a 5B autoregressive world model that conditions on joint keyboard and text inputs for playable world generation. It uses unified action/text conditioning with jointly annotated videos, event-scale distillation from a segment-level teacher to a block-level causal student, and four-step generation with context-preserving streaming. Evaluation uses 158 WBench Navigation cases with overall and consistency scores.

Key Results

Zing-0.5 achieves an overall score of 81.0 and a consistency score of 88.5 across 158 WBench Navigation cases. It also supports 832 x 480 inference at 24 FPS at an estimated server rental cost of approximately USD 0.009 per stream-minute, with a joint-control demonstration showing text-directed event change during continued navigation without restarting generation.

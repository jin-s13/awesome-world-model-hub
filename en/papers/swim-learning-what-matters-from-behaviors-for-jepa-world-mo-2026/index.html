Reasoning

The paper addresses a clear limitation in JEPA world models by learning state weights from offline trajectories, showing consistent planning improvements over uniform weighting. Deep Analysis

Innovations

  • Introduces SWIM, which learns state-feature weights from offline trajectories by predicting recorded actions from current states and observed future displacements.
  • Uses the learned inverse-dynamics weights to define a weighted state metric for state-supervised JEPA training, demonstrated by aligning latent and state distances.
  • Applies the inverse-dynamics model only during training, enabling image-based planning with no additional planning-time computation.

Methodology

SWIM trains an inverse-dynamics model on offline trajectories to predict actions from current states and future displacements, yielding weights for each state feature. These weights define a weighted state metric used to supervise a JEPA world model by aligning latent and state distances. Evaluation compares planning success against uniform state weighting across five simulated robotic manipulation tasks.

Key Results

Across five simulated robotic manipulation tasks, SWIM consistently improves planning success over uniform state weighting.

H-JEPA datasets Data for the H-JEPA code release (hierarchical JEPA world models). Image columns are stored with lossless Blosc-Zstd compression inside the HDF5 files; h5py with hdf5plugin reads them directly. The repository mirrors $HJEPA_HOME, the data root the code reads from, so a download with --local-dir $HJEPA_HOME puts every file where the code expects it.

研究路线

生成式视频世界模型架构

从高维观测学习像素或潜在动力学，用于视频预测、规划推演或机器人策略预训练。

尚未覆盖：长时域一致性、记忆、动作控制、物理合理性及跨域迁移仍未充分验证。
上下文感知与组合动力学建模

用上下文变量或语言分解原语条件化世界模型，提升对未见动力学、任务或物体-动作组合的泛化。

尚未覆盖：假设上下文可观测或指令可解析为已知原语；证据仅覆盖有限任务和基准。
世界模型评估与一致性基准

通过专门数据集和指标量化空间一致性、记忆一致性与动作控制能力，而非仅看生成保真度。

尚未覆盖：证据偏向数据集与基准构建；标准化、基线广度和与下游策略表现的关联仍开放。

研究共性

  • 研究将世界模型学习视为高维视频或动力学预测，近期架构多采用扩散Transformer、Transformer-VAE混合或循环状态空间模型。
  • 多项工作在重建之外加入辅助信号，如掩码重建、深度预测、关键点动力学、上下文解耦或视频-动作耦合。
  • 泛化评估常涉及未见上下文、零样本数据集、未见目标组合或跨域场景，而非仅看训练分布重建。
  • 基准工作将长期记忆一致性和动作控制识别为当前世界模型尚未解决的核心能力。

关键差异

  • 表示方式不同：扩散式视频生成、随机Transformer-VAE潜在动力学、上下文循环状态空间条件化并存。
  • 监督信号不同：纯RGB生成、物理/几何信息、语言原语分解、动作-视频耦合各有侧重。
  • 评测目标不同：Atari模型强化学习、驾驶视频预测、机器人操作、Minecraft开放域一致性等定义不同的成功标准。
  • 动作接口不同：有的将动作作为视频预测条件，有的联合建模动作-视频扩散或用想象轨迹训练策略。
  • 证据重心不同：一些报告基准分数提升，一些侧重数据集构建且结果比较不完整或开放。

开放问题

  • 哪些训练目标最能保持动作条件下生成中的长期记忆与空间一致性？
  • 物理信息或上下文世界模型目标能否在没有可观测上下文的场景中迁移到已报告任务族之外？
  • 已报告的泛化增益有多少来自世界模型表示，多少来自数据集、动作接口或评测协议？
  • 如何在开放域环境中标准化空间一致性与动作控制指标，哪些指标能预测下游策略成功？
  • 统一视频-动作预训练能否在保持可控生成的同时有效利用无动作视频？

研究路线

具身机器人世界模型与视频生成

以语言、目标或动作条件生成机器人执行视频，用于策略训练与评估。

尚未覆盖：对未见原语组合和真实机器人跨本体迁移的泛化仍有限，物理合理性及部署证据仍不足。
自动驾驶世界模型与仿真

对驾驶场景进行长时域、多视角预测，并支持闭环仿真与策略评估。

尚未覆盖：驾驶基准提升能否转化为真实安全或运营结果尚不明确，跨数据域零样本迁移只得到部分验证。
基于模型的强化学习世界模型

利用少量交互学习潜在动力学，提高视觉控制与游戏环境中策略训练的样本效率。

尚未覆盖：上下文可观测等假设以及少量任务评测，使未知或不可观测动力学下的零样本泛化仍未被充分验证。
世界模型记忆、空间一致性与动作控制评测

量化生成轨迹在回环、视角变化和动作控制下是否保持时间稳定和空间连贯。

尚未覆盖：基准较新，主要揭示现有模型挑战；动作空间、场景覆盖和长时域一致性解决方案仍不完整。

研究共性

  • 近期应用集中在以动作、语言目标或任务上下文为条件的生成式视频轨迹，用于具身与交互场景。
  • 除RGB生成外，普遍加入辅助监督或约束，如掩码重建、深度/关键点、上下文条件或联合扩散，以改善一致性和泛化。
  • 评测从视觉真实感扩展到长时域稳定性、空间或记忆一致性以及动作可控性。
  • 多篇应用论文在展示基准提升时，局限性说明或真实环境部署证据较少，验证缺口仍然存在。

关键差异

  • 表示方式不同：统一视频-动作扩散、分解为原语的视频生成器、循环状态空间或潜在动力学模型并存。
  • 监督与假设不同：部分方法依赖无动作视频或语言目标，部分需要成对视频-动作数据，部分假设上下文值可观测。
  • 评测目标不同：分别强调驾驶数据集真实感、Atari 100k人类表现、Minecraft循环空间一致性、机器人仿真执行和物理合理性。
  • 交互模式与部署场景不同：闭环驾驶、机器人想象与策略训练、游戏/导航循环交互隐含不同的动作空间和时间尺度。
  • 一致性约束方式不同：掩码重建、深度与关键点动力学、场景图或回环重访指标被分别采用。

开放问题

  • 驾驶世界模型在验证集和零样本数据集上的提升是否对应真实安全或运营收益？
  • 具身世界模型能否在不假设上下文可观测的情况下，泛化到未见物体、动作或本体？
  • 哪些指标能同时评估长时程记忆一致性、动作可控性和物理合理性？
  • 大规模视频-动作联合扩散预训练策略在不同硬件与实施例上的真实机器人收益是否优于模仿学习？

研究路线

基准任务与数据集设计

构建共享任务与数据集，例如 Minecraft 循环导航视频和多场景受控视频片段，使世界模型的空间、记忆与动作能力可比。

尚未覆盖：这些任务分布是否迁移到真实部署设置并覆盖世界模型预期用途，尤其是长时域与跨动作空间场景，仍待验证。
指标与压力测试设计

在总分之外检验预测、空间一致性、时间稳定性、上下文连贯性与动作控制；例如场景图一致性分数和记忆/动作控制指标。

尚未覆盖：代理指标与用户真正关心的下游决策之间的一致性尚未证明；长时记忆一致性和跨动作空间泛化仍然困难。
可比基线与报告规范

通过标准化数据集和指标建立共同评测目标，如驾驶数据集、Atari 100k、CARL 与机器人预训练数据，使结果可审计和可比。

尚未覆盖：基准结论在不同实现和算力预算下是否稳定尚未显示；若干来源缺少完整局限与工件报告，形成验证缺口。

研究共性

  • 共享任务与标准化 rollout 被视为比较世界模型能力、超越定性视频样本的必要条件。
  • 动作条件评测是共同焦点：模型是否能在控制输入下产生跨视角、跨时间一致的未来观察。
  • 仅看总分被认为不足；近期证据加入空间一致性、记忆一致性、物理合理性或归一化下游控制指标。
  • 可复现性通过发布数据集或代码来体现，但部分来源缺少局限与报告细节，可比性仍有限。

关键差异

  • 表示方式：基于扩散的生成、Transformer-VAE 随机模型、带可观测上下文的循环状态空间模型，以及物理信息深度/关键点监督，差异明显。
  • 评测目标：单任务强化学习性能、开放域循环导航、驾驶多视角预测、机器人视频-动作预训练或物理合理性。
  • 交互模式：无动作视频生成、动作条件控制和闭环复现评测在不同研究中使用。
  • 部署场景：模拟游戏环境与真实世界规模的驾驶和机器人数据；这改变了一致性与控制指标可支撑的结论。

开放问题

  • 循环导航的空间一致性分数和记忆/动作控制视频能否预测真实驾驶或机器人部署中的效用？
  • 当前任务分布是否覆盖世界模型预期帮助的设置，尤其是长时记忆与跨动作空间泛化？
  • 在可比算力和实现条件下，哪种表示或监督信号更利于记忆一致性？
  • 当若干高证据来源缺少完整局限与工件报告时，基准结论在不同实现和算力预算下是否稳定？
  • 代理指标应如何与下游决策而非像素级或聚合基准对齐？

研究路线

可运行的驾驶与机器人闭环模拟器流水线，如 FAR-Drive、Vista、Terra

将预训练或学习得到的视频生成器转化为动作条件化的多视图或未来帧可部署世界模拟器，部分方法满足低延迟约束。

尚未覆盖：nuScenes和特定传感器配置之外的泛化、自回归自条件下的长时程退化，以及单GPU验证之外的扩展部署。
可控性与一致性基准，如 LoopNav、Terra ACT-Bench

通过数据集和评分方法衡量动作保真度或空间一致性，补充 FID/FVD 等视觉质量指标。

尚未覆盖：部分基准论文未报告实验结果，指标覆盖局限于 Minecraft 循环或 nuScenes 等窄域，且分数与下游策略迁移的关系未建立。
上下文、物理与跨具身感知的具身世界模型，如 cRSSM、RoboScape、RynnWorld-Latent

通过上下文条件、物理启发任务或共享潜在动作接口，改善零样本动力学泛化、物理合理性或跨具身视频预测。

尚未覆盖：上下文可观测等假设、仅在两个 CARL 任务或窄机器人场景上评估、局限性说明缺失，以及独立复现未验证。

研究共性

  • 动作条件化是视频生成用作模拟器的关键，但仅靠视觉保真度不足以支持闭环使用。
  • 针对运动、结构、深度、关键点或动作对齐的结构化损失或模块能提升可控性和动态一致性。
  • 显式空间一致性或动作保真度基准正在作为 FID/FVD 等视频质量指标的补充。
  • 闭环和长时程行为是驾驶、机器人和游戏式交互场景中的共同关切。
  • 若干工作公开了代码或数据集，但跨团队独立复现仍是验证缺口。

关键差异

  • 条件接口与监督信号不同：可观测上下文值、通用潜在动作、轨迹与多视图控制、物理启发的深度/关键点监督。
  • 评测目标不同：循环导航中的空间一致性、自动驾驶中的动作保真度、视觉质量加策略成功、跨具身机器人适配。
  • 训练路线不同：修改 Dreamer v3 等基于模型强化学习的世界模型、联合训练物理信息视频生成，或适配预训练视频模型。
  • 部署设置不同：单GPU低延迟闭环驾驶、机器人策略训练与评估、游戏/机器人模拟中的优先想象。

开放问题

  • 当前基准分数能否预测未见环境和传感器配置下的下游闭环策略成功率？
  • 如何在不收集极长专家序列的情况下测量长时程空间和时间一致性？
  • 在 CARL 两个任务或 nuScenes 之外，需要多少监督或上下文可观测性才能稳健泛化？
  • 在受限硬件上实时部署的速度-保真度-可控性边界在哪里，如何从单GPU验证扩展到多GPU？
  • 物理合理性与动作遵循还缺少哪些指标，尤其是当部分基准论文未报告实验结果时？

研究路线

面向具身控制的动作条件化视频动力学

从动作序列学习未来观测帧，用于策略学习、逆动力学、规划及跨机器人数据集的更快仿真。

尚未覆盖：长程物理与因果持续性、动作-帧假设的形式化验证，以及超出已评测机器人或领域的泛化边界。
世界模型轨迹的奖励、偏好与验证对齐

将生成轨迹与物理真实性、任务逻辑、人类偏好对齐，或改善空间推理中测试时视图选择的可靠性。

尚未覆盖：偏好监督可能主观或成本高，跨基准缩放不一致，奖励或验证器在分布偏移下的校准未知。
状态与动态的概念分类及功能性评测

澄清隐式与显式状态构建，组织动态建模方式，并主张超越视觉保真度的功能性基准。

尚未覆盖：该分类法缺少实验验证，也尚未证明能改变模型设计或评测实践。
世界模型的缩放与边界证据

在特定场景中建立模型规模或测试时计算与视频质量、空间推理改进之间的关联。

尚未覆盖：没有经过验证的形式保证或缩放规律；部分基准上测试时缩放失效，模型规模缩放证据有限。

研究共性

  • 世界模型越来越多地被操作化为动作条件化生成式视频模型，而不是单纯的分析形式对象。
  • 视觉质量单独不足；物理一致性、动作对齐、任务逻辑或因果持久性正在成为评测目标。
  • 大规模动作-观测预训练与后训练对齐能够改善可控性、保真度或下游策略与规划效果。

关键差异

  • 是适配冻结的预训练视频生成器而不访问参数，还是训练统一的动作-视频模型并使用模态专用条件化。
  • 以何种监督信号对齐世界模型：人类偏好奖励、基于偏好的 DPO、帧锚定可验证断言，还是低级动作可控性。
  • 首要评测目标是帧质量与动作对齐、物理合理性与轨迹一致性、空间推理基准缩放，还是功能性状态/动态持久性。
  • 状态应通过上下文或潜在压缩隐式表示，还是通过架构模块显式表示；扩散 Transformer 与掩码自回归何者更优。

开放问题

  • 动作条件化视频模型背后的形式条件或假设是否与部署中的经验行为一致，边界违例发生在何处？
  • 为何测试时验证器缩放在一个空间推理基准有效而在另一个上无效，是否表明当前世界模型存在信息瓶颈？
  • 偏好对齐的世界模型能否无需昂贵的新人类偏好数据就迁移到接触丰富操作之外的任务？
  • 零样本物理合理性基准反映的是真实世界因果正确性，还是仅在策划评测场景中的分布一致性？
  • 在若干高评分论文缺少代码、数据集或局限细节的情况下，所报告提升的可复现性如何？

世界模型经验基准与仿真器构建

提供具体模型、数据集和指标，用于机器人想象、自动驾驶仿真、自我运动与物体动态控制、开源实时模拟及视线外持久性。

具身自主中的开放问题与缺口映射

将文献覆盖转化为长期记忆、实时交互、细粒度控制和仿真到现实迁移等具体缺口。

尚未覆盖：缺口优先级未量化，哪些问题对下游自主能力提升最大仍不清楚。

研究共性

  • 世界模型被视为统一的底层能力，用于逼真视觉合成、自主交互与环境动态预测。
  • 长期时间一致性与持续状态或记忆是所分析方法和综述反复出现的要求。
  • 评测应从图像质量转向闭环、可控、具身或资源感知证据。

关键差异

  • 表示选择不同：基于语言组合的视频生成、持久全局3D与动态实体状态、对观测-状态-动作节点进行统一自回归建模、以及潜在连续/离散混合表示。
  • 监督与评测目标不同：仿真机器人执行、逼真合成与地理参考、细粒度自我运动与物体动态控制、视线外持久性。
  • 交互与部署场景不同：从开源实时视频模拟到自动驾驶数据集和多智能体交通仿真。
  • 理论分类法缺少实证验证，方法与基准论文报告量化结果，这造成可验证性差异而非必然是贡献差异。

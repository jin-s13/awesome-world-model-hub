研究路线

带重建或物理先验的生成式视频世界模型架构

从视觉观测生成长时域、多视角和物理更合理的视频；包括掩码重建、深度、关键点动力学与组合语言原语等。

尚未覆盖：超出驾驶/机器人数据集的迁移性以及自动物理一致性度量仍缺乏证据；若干摘要未给出显式局限。
基于随机序列模型的潜空间模型化强化学习

学习紧凑潜状态动力学，实现样本高效RL，并在可观测上下文变量可用时改进零样本泛化。

尚未覆盖：仅展示有限基准设置；上下文可观测假设、模型收益与策略训练的分离尚未完全验证。
动作-视频耦合扩散接口

在统一Transformer中表示策略、前向/逆动力学和视频生成，支持大规模机器人数据及无动作视频预训练。

尚未覆盖：真实机器人部署与长时域闭环控制未在摘要中证实；耦合贡献与数据规模贡献仍不清晰。
世界模型一致性与动作控制评测

用循环导航、场景图分数和闭环重访设定，评测记忆/空间/动作控制，超越像素级生成质量。

尚未覆盖：指标到下游任务的迁移尚未证明；一个基准只报告构建而无实验结果；场景覆盖限于模拟/游戏。

研究共性

  • 近期工作趋向于从视觉观测和动作或上下文学习预测性世界模型，并将学习到的动力学用于策略训练或评测。
  • 评测从单步视觉相似性转向长时域、多视角、零样本、物理合理性和记忆/动作一致性。
  • Transformer与扩散架构在视频生成和动作耦合方法中常见，潜状态空间模型在样本高效RL中仍常见。
  • 缺少局限性说明和可复现证据不完整是跨论文的验证缺口。

关键差异

  • 表示层级：潜变量循环状态空间轨迹、像素空间视频生成与统一动作-视频扩散之间存在差异。
  • 训练目标：掩码重建、变分序列建模、物理先验深度/关键点任务、组合语言解析或耦合动作预测不同。
  • 评测目标：RL样本效率与零样本策略泛化、视觉保真度与物理合理性、一致性与动作控制基准各有侧重。
  • 动作与监督假设：上下文可观测、无动作视频预训练、语言解析原语组合等设定不一致。

开放问题

  • 已报告在Atari 100k、CARL、Nuscenes/OpenDV-2K/Waymo、RT-X、Minecraft和MIND场景的提升能否迁移到真实世界或未见动力学？
  • 策略改进中有多少来自世界模型本身，而非规划器、策略优化器、数据规模或动作接口设计？
  • 哪些一致性指标能预测下游规划与控制成功，其分布偏移下的失效模式是什么？
  • 高排名工作中缺少哪些消融证据来分离架构变化、训练配方、数据多样性和基线强度？
  • 能否在无动作视频、动作标注机器人数据与上下文条件动力学之间组合，而不引入可观测性或原语覆盖的隐藏假设？

研究路线

具身与领域任务迁移

将世界模型适配到机器人与上下文控制任务，通过学习潜在动力学或生成动作/上下文条件视频来支持策略训练与零样本泛化。

尚未覆盖：跨本体和真实机器人迁移尚未充分验证；组合式或上下文条件方法依赖已见原语或可观测上下文。
自动驾驶与仿真应用

预测多视角、长时域驾驶场景，用于仿真、策略评测和跨数据集迁移。

尚未覆盖：生成指标提升尚未与真实世界安全或运营结果建立联系，局限性也常未报告。
交互式智能体与游戏

在受控、循环或游戏环境中评估和改进世界模型的记忆一致性、动作可控性和样本高效强化学习能力。

尚未覆盖：当前证据显示长期记忆和跨动作空间泛化较弱；部分评测提出后未报告基线结果。

研究共性

  • 面向应用的世界模型通常被构造为以动作、上下文或语言为条件的未来观测生成模型。
  • 多数方法结合可扩展的序列或生成架构与辅助任务或预训练目标，以提升保真度、可控性或下游策略学习。
  • 评测正从单任务分数扩展到长时域生成、空间/记忆一致性、动作可控性、零样本迁移和下游机器人策略效用。
  • 数据集、基准或代码发布逐渐常见，但局限性报告仍不均衡。

关键差异

  • 表示不同：潜在循环状态空间模型优化紧凑动力学，而扩散与 Transformer 视频模型优化高维感知保真度。
  • 监督不同：掩码重建、物理信息辅助信号、语言解析原语组合、统一视频-动作扩散和想象轨迹策略学习优化不同能力。
  • 评测目标不同：闭环记忆/动作一致性、零样本上下文或数据集迁移、人类归一化游戏分数、物理合理性与下游机器人执行尚未统一。
  • 部署设置不同：驾驶强调多视角与跨数据集预测；机器人强调目标/动作组合和物理真实性；交互游戏环境强调循环记忆与样本高效交互。

开放问题

  • 生成世界模型在驾驶、机器人仿真或游戏环境中的收益是否迁移到真实安全、物理执行或未见环境动力学？
  • 空间一致性和动作控制能否在长循环和变化动作空间、本体或目标下保持？
  • 组合式或上下文模型能否处理全新原语或未观测上下文，而不仅是训练条件重组？
  • 哪种评测协议能联合认证物理合理性、记忆一致性和策略效用，同时不把热度或阅读优先分数混同为证据？

研究路线

空间与记忆一致性基准

通过循环导航和多场景视频基准，评估世界模型在长时空间与记忆一致性上的表现。

尚未覆盖：场景图一致性可能忽略像素或几何细节；领域覆盖限于Minecraft和少量场景，且缺少完整社区排行榜证据。
标准视觉控制与强化学习评测

利用Atari 100k、CARL、Nuscenes、OpenDV-2K、Waymo等共享测试比较模型控制或视觉预测能力。

尚未覆盖：聚合分数和特定基准协议尚不足以检验长时域、零样本、跨动作与跨实现稳定性。
物理信息与具身评测

通过RGB视频生成、时间深度、关键点动力学和动作耦合机器人评估来检验物理合理性和下游策略效用。

尚未覆盖：视觉保真和物理合理性与真实机器人任务成功率或稳定物理指标的一致性尚未建立。
上下文泛化压力测试

通过改变可观测上下文和任务动力学，检验零样本与跨上下文的泛化能力。

尚未覆盖：现有压力测试多假设上下文可观测且仅覆盖少量CARL任务，更广未知动力学和动作空间迁移未验证。

研究共性

  • 行动条件生成和闭环或循环式评估逐渐被视为世界模型的核心能力。
  • 单一聚合视觉或奖励指标不够，需同时检验一致性、可控性、泛化性和物理合理性。
  • 共享基准提高可比性，但多数收益是基准特定结果，未证明部署鲁棒性。
  • 阅读优先分数、引用影响和标签热度与方法学证据分离；部分论文局限字段为空或缺少OpenAlex信号，存在验证缺口。

关键差异

  • 表示方式：扩散Transformer和扩散生成器、VAE/Transformer循环状态空间、物理信息联合RGB-深度-关键点模型并存。
  • 评测目标：Atari控制回报、驾驶长时域和多视角预测、具身机器人视觉质量、零样本上下文泛化各有侧重。
  • 交互模式：闭环重访动作控制、循环导航、无动作视频预训练或环境特定动作空间不同。
  • 指标重点：人类归一化分数与视觉保真、场景图空间一致性、记忆与动作控制、物理合理性等不同。
  • 部署场景：模拟Atari、Minecraft、CARL环境与真实驾驶和机器人场景之间存在差异。

开放问题

  • 新的空间一致性和动作控制探针能否覆盖世界模型预期发挥作用的真实部署分布？
  • 场景图一致性、视觉保真和人类归一化回报等代理指标是否与下游驾驶或机器人决策一致？
  • 在多篇论文缺少局限性说明和工件验证的情况下，基准结论在不同实现和算力预算下是否稳定？
  • 记忆和动作控制评测在视角、动作空间和未见物理上下文之间能多大程度迁移？
  • 需要怎样的共享排行榜和报告规范来弥合基准构建与可审计模型比较之间的差距？

研究路线

可控世界模型模拟器与开环/闭环生成

将动作、轨迹、上下文或物理线索转化为未来视频或状态推演，用于驾驶、机器人、游戏和规划。

尚未覆盖：证据集中在 nuScenes、CARL 两个任务、Minecraft 或受限机器人场景；长时程一致性、视觉细节和训练域外泛化仍不充分。
世界模型能力基准与评测框架

提供空间一致性或动作保真度的数据集与指标，使比较不局限于像素级真实感。

尚未覆盖：部分摘要未报告实验结果或局限性；传感器和域覆盖较窄，空间、动作、物理与规划指标尚未统一。
世界模型驱动的规划、策略训练与部署栈

利用模拟未来作为训练或评估环境及规划器，包括优先想象、基于模型的强化学习和亚秒级单 GPU 驾驶模拟。

尚未覆盖：多 GPU、多智能体或复杂真实场景可扩展性证据不足；若干系统缺少局限性分析或独立复现证据。

研究共性

  • 生成模型被普遍视为可学习的世界模拟器，可用动作、上下文或物理结构条件化未来推演，而非仅作为无条件视频生成器评价。
  • 正在出现面向控制保真度、空间一致性和物理合理性的专门基准与指标，而不仅是视觉真实感。
  • 下游可用性越来越多通过策略训练、规划、模拟真实感或闭环驾驶来评估，而非仅看单独生成质量。
  • 许多 top 论文提供代码或数据集等可复现信号，但本证据包中缺少引文和图谱声望证据。

关键差异

  • 条件与监督信号不同：基于模型的强化学习使用可观测上下文值，驾驶模拟使用动作或轨迹对齐，具身视频生成使用联合物理关键点或深度任务。
  • 评测目标不同：有的强调循环导航场景图空间一致性，有的强调动作保真度，还有的报告 FID/FVD、规划性能或零样本泛化。
  • 时序与架构选择不同：循环状态空间世界模型、帧级自回归扩散 Transformer，以及基于预训练视频生成器的适配器并存。
  • 交互与部署假设不同：部分系统展示闭环单 GPU 亚秒级延迟，多数未解决实时、多 GPU 或外部基础设施约束。

开放问题

  • 这些系统如何迁移到 nuScenes、CARL、Minecraft 或受限机器人场景之外的传感器配置、域和环境？
  • 何种评测协议能同时反映空间一致性、动作保真度、物理合理性和下游规划价值，而不只是像素级指标？
  • 长时程闭环推演在自回归条件下能稳定到何种程度，退化何时会不安全地影响规划或策略训练？
  • 在缺少局限性证据的情况下，单 GPU 低延迟能否在多 GPU、多智能体或复杂真实部署中保持？
  • 多个摘要未报告局限性或结果，现有基准和工件能否支持跨团队独立复现？

研究路线

统一动作-视频生成式预训练

在单一模型中耦合动作与视频生成，从大规模机器人数据中学习联合策略与动力学表示。

尚未覆盖：证据集中在机器人操作、视觉可控性和速度；长时程物理一致性与分布外迁移仍未充分验证。
预训练视频扩散模型的动作条件适配

在不访问模型参数的情况下复用闭源视频生成先验，通过轻量动作条件适配器构建世界模型。

尚未覆盖：依赖动作标注领域数据，并假设预训练视频先验足够；超出已测游戏和机器人领域的泛化尚未建立。
生成轨迹的物理与偏好对齐

后训练世界模型以减少非物理行为，并提升物理保真度、任务逻辑、具身合理性和视觉质量。

尚未覆盖：人类偏好数据昂贵且主观，证据集中在接触丰富操作，缺少更广泛领域验证或形式保证。
状态、动态与空间推理的概念和评测分析

澄清状态构建和动态建模缺口，并检验世界模型轨迹是否能支持可靠推理、规划或测试时缩放。

尚未覆盖：分类法和验证器框架能否转化为更好的模型设计、持久状态和因果推理仍未解决。

研究共性

  • 动作条件视频生成被视为具身世界模型的核心测试平台。
  • 仅凭视觉质量不够；物理合理性、任务逻辑、动作对齐或下游决策质量正被纳入额外标准。
  • 大规模机器人或视频先验被认为有助于提升泛化性和可控性。

关键差异

  • 表示方式不同：统一动作-视频扩散和掩码自回归，与通过学习掩码适配现有视频扩散模型不同。
  • 对齐策略不同：多维奖励模型加RL式后训练，与DPO式解耦判别器或无显式物理对齐不同。
  • 评测目标不同：下游策略或规划相关性与模拟器一致性、视觉保真与可控性、物理合理性与轨迹一致性、空间推理各有侧重。
  • 部署假设不同：黑盒使用预训练视频扩散模型、在策展机器人数据上可控预训练、或带偏好标注后训练存在差异。

开放问题

  • 生成轨迹能否在足够长时间内保持持久状态和因果动态，以支持可靠规划与细粒度空间推理？
  • 形式化分类法或验证器框架能否转化为超越视觉基准的模型设计和评测改进？
  • 物理对齐能否泛化到接触丰富操作以外的未知本体、任务和场景？

研究路线

世界模型的分类与路线图综合

自动驾驶仿真与闭环评测

基准设计的开放问题与缺口映射

把文献覆盖转化为具体评测缺口，如视线外动态基准和细粒度物体控制指标。

尚未覆盖：哪些缺口应优先解决，以及不同基准之间是否可比较仍不明确。

研究共性

  • 世界模型被普遍视为未来视觉或多模态观测的生成式预测器，驾驶、机器人和智能体仿真是常见应用领域。
  • 显式结构被用于提高一致性或可控性，包括语言原语、持久状态、稀疏特征、自我轨迹和潜在分类。
  • 评测是共同薄弱环节：论文呼吁闭环、长时程和视线外基准，但不少方法文献缺少系统基线或限制说明。

  • 部署场景不同：有仿真为主，有驾驶数据闭环，也有强调开源交互生态的方案。

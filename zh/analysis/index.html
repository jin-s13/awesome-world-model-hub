研究路线

生成式扩散/Transformer视频世界模型（用于具身与驾驶场景）

从上下文、语言或先前帧预测长时域或多视角视频，常通过掩码重建、组合原语或物理辅助任务实现。

尚未覆盖：在已报告的驾驶/机器人数据集之外的迁移尚不确定；视觉保真、物理合理性及未见原语/上下文的泛化未被充分隔离。
基于随机状态空间/Transformer的世界模型用于基于模型的强化学习

学习紧凑潜在动力学，用于想象轨迹和有限交互下的策略改进。

尚未覆盖：证据限于CARL任务或Atari 100k等较窄套件；可观测上下文假设及与规划器/控制器收益的分离仍需检验。
统一视频-动作扩散预训练与动作接口模型

将视觉生成与动作预测/控制耦合在单一模型中，支持策略、前向/逆向动力学或无动作视频预训练。

尚未覆盖：跨动作空间泛化、收益是否来自预训练规模、模态时间步控制或下游策略适配仍未明确。
物理信息具身世界模型

增加深度和关键点动力学任务，以改进生成机器人视频中的三维几何一致性和物理合理性。

尚未覆盖：将物理任务与架构/数据规模分离的消融、模拟/多样机器人场景之外的鲁棒性、下游策略评估仍部分开放。

研究共性

  • 近期世界模型方法倾向于使用Transformer或扩散组件配合自监督辅助任务进行生成式视频/动力学预测。
  • 正在从把动力学预测与决策分离，转向将视觉生成与动作、控制、上下文或物理信号统一。
  • 评测正从单帧视觉质量或任务得分扩展至长时域、空间、记忆和动作控制一致性。
  • 论文通常发布代码或数据集，但局限报告和消融不一致。

关键差异

  • 表示与损失不同：循环状态空间/变分模型、扩散Transformer、组合语言原语分解以及统一视频-动作扩散。
  • 监督信号不同：可观测上下文变量、语言指令、动作-视频对或深度/关键点等辅助物理任务。
  • 评测目标不同：游戏基准表现、驾驶视频预测、机器人视频计划/执行以及开放域记忆/动作控制基准。
  • 交互设置不同：有些在想象轨迹中学习策略，有些在机器人数据集上预训练以供下游控制，有些仅定义基准协议而未报告策略结果。
  • 领域假设不同：已知上下文值、预定义语言原语、共享或多样动作空间，以及仿真与真实数据集评估的差异。

开放问题

  • 基于上下文和组合的世界模型能否泛化到CARL、RT-X、驾驶和Minecraft证据之外的未见上下文、原语或领域？
  • 报告的性能提升有多少来自模型架构，而不是数据规模、辅助任务、预训练或下游规划器与控制器？
  • 哪些标准化指标能可靠比较视频世界模型的空间一致性、记忆一致性和动作控制，同时避免过拟合像素级或场景特定线索？
  • 验证缺口在哪里：若干高排名论文缺少局限或在摘要中未报告实验结果，基线、消融和鲁棒性证据需要后续补充。

研究路线

自动驾驶仿真与场景预测

生成驾驶场景的长时域和多视角视频，以支持闭环仿真和策略评测。

尚未覆盖：基准改进与真实安全/运营结果之间的一致性，以及跨驾驶数据集的零样本迁移仍未充分验证。
机器人视频生成与动作耦合世界模型

生成物理合理的机器人视频，并耦合视频与动作扩散，以从机器人数据集中学习策略、前向动力学和逆动力学。

尚未覆盖：对未见动作原语、不同本体和真实机器人执行的泛化仍局限于仿真或特定数据集。
基于模型强化学习的潜在或上下文想象

通过在世界模型想象轨迹上训练智能体，实现视觉控制任务的高效策略学习，并通过上下文条件化提升零样本泛化。

尚未覆盖：评测范围较窄，假设上下文可观测，且尚未验证能否扩展到Atari/CARL之外的任务。
交互式世界模型评估基准

在开放世界或循环导航等交互环境中，探测空间一致性、记忆和动作可控性。

尚未覆盖：尚缺少这些基准分数与下游任务表现或模型改进之间的证据联系。

研究共性

  • 近期应用研究集中在从大规模视觉数据集学习动作条件或目标条件的生成式世界模型。
  • 评估正从短时域帧质量转向长时域动力学、物理合理性和交互一致性。
  • 掩码、深度与关键点预测、物理知识或上下文条件化等领域专用归纳偏置能改善任务相关预测。
  • 可复现证据参差不齐：基准工作倾向发布数据集，而部分方法论文在可见证据中缺少明确的局限说明或代码细节。

关键差异

  • 监督信号不同：纯视频生成、视频-动作扩散耦合、潜在策略想象和物理辅助任务训练了不同的世界模型目标。
  • 评测目标不同：驾驶论文使用NuScenes/OpenDV-2K/Waymo，机器人论文使用RT-X并结合仿真或策略成功，游戏/强化学习论文使用Atari/CARL或循环式Minecraft探针。
  • 交互模式不同：开环预测、闭环动作条件 rollout、在想象轨迹上训练策略、以及基于基准的动作可控性并不等价。
  • 表示选择不同：扩散Transformer、循环状态空间模型、VAE-Transformer混合以及统一多模态扩散以不同方式编码状态和动作。

开放问题

  • 更强的驾驶世界模型基准是否能迁移到真实安全或运营结果？
  • 机器人视频世界模型能否泛化到训练分布之外的未见动作原语或不同本体？
  • 视觉保真度、空间一致性、记忆一致性或动作可控性中，哪些可测量属性最能预测下游策略成功？
  • 当前世界模型在循环、视角和动作变化下如何保持长时域记忆一致性？
  • 当真实世界上下文仅部分可观测时，上下文可观测假设对零样本泛化有多大限制？

研究路线

基准任务与数据集设计

构建共享任务和数据集，使世界模型的空间一致性、记忆一致性与动作控制具备可比性；代表性包括LoopNav和MIND。

尚未覆盖：对长时域记忆、跨动作空间、多视角开放世界和具身场景的覆盖仍不确定；LoopNav摘要未报告基线实验结果。
指标与压力测试设计

通过场景图一致性、记忆/动作控制检查、视觉保真度、物理合理性及Atari人类归一化分数，检验总分之外的预测、可控性、鲁棒性和一致性。

尚未覆盖：代理指标与下游决策效用的对齐尚未验证；多数指标绑定特定基准，缺少真实场景或策略相关性的直接证据。
可比基线与报告规范

通过复用Dreamer v3、Atari 100k、CARL、Nuscenes、OpenDV-2K、Waymo及先前最先进的驾驶世界模型等基线和套件，使结果可审计。

尚未覆盖：跨实现与算力预算的稳定性未报告；多篇论文局限性字段为空，可复现性和边界条件仍是证据缺口。

研究共性

  • 世界模型评测正趋向以视觉、动作条件或闭环推演作为证据，而非仅使用标量奖励。
  • 研究者普遍认为需要通过专门数据集和指标测试空间一致性、记忆、动作控制、视觉质量和物理合理性。
  • 开放数据集与基准被视为评测导向工作的重要贡献。

关键差异

  • 评测目标不同：导航循环一致性、跨视角记忆/动作控制、强化学习归一化分数、机器人视觉与物理合理性。
  • 表示与监督不同：扩散视频模型、Transformer-VAE随机模型、循环状态空间模型和物理信息损失优化不同信号。
  • 交互模式不同：开环视频预测、闭环重访导航、动作条件生成以及在习得模型中进行策略评估。
  • 部署场景不同：模拟游戏、Minecraft、驾驶、机器人操作和大规模多任务机器人数据集导致不同的泛化预期。

开放问题

  • 空间一致性和记忆/动作控制指标与下游策略质量或真实部署表现的关系是什么？
  • 基准任务能否在长时域、跨动作、多视角和开放世界设置中保持覆盖而不对特定视觉过拟合？
  • 在局限性细节缺失的情况下，报告的基准增益能否在不同实现、基线和算力预算下复现？
  • 上下文条件或物理信息世界模型能否泛化到当前证据中的狭窄任务套件之外？

一致性与可复现性基准工件

通过数据集、指标与评测协议使空间或动作一致性可检查、可比较

尚未覆盖：跨团队和基础设施的独立复现、基线细节与限制说明在多个系统中仍然不完整

研究共性

  • 系统正汇聚到以动作条件未来帧/世界模型生成为核心抽象，用于仿真、评测和策略学习。
  • 评测正从单一视觉质量扩展到空间一致性、物理合理性或动作忠实度等显式信号。
  • 闭环部署逐渐成为明确要求，无论是以真实机器人在线学习还是单 GPU 低延迟驾驶仿真的形式。

  • 表示方式：循环状态空间动力学与扩散或自回归视频生成形成不同建模路径。
  • 监督与评测目标：物理信息深度/关键点损失、上下文条件、轨迹标注视频和循环导航基准强调不同证据。
  • 部署场景：直接在真实世界学习的物理机器人与面向大规模自动驾驶仿真的系统目标不同。
  • 指标选择：FID/FVD 视觉质量、动作忠实度、场景图一致性及下游策略效用尚未统一。

世界模型声明的概念分类与评估边界

澄清状态构建、动力学建模，以及视觉生成与功能性世界模型之间的评估差距。

尚未覆盖：所提分类缺少直接经验证据证明其会改变模型设计；面向持久性和因果推理的功能基准仍不成熟。

研究共性

  • 只有当动作或状态信息被注入，并评估决策相关行为时，视频生成才被视作候选世界模型。
  • 机器人轨迹数据可用于预训练或适配，但仅凭视觉保真度不被视为世界模型质量的充分证据。
  • 近期研究趋向于加入物理合理性、任务逻辑或可验证推理信号，而不是仅依赖帧生成指标。
  • 评估实践正转向功能测试，如规划、策略相关性、轨迹选择或具身零样本基准。

关键差异

  • 表示与生成机制不同：独立模态时间步的扩散Transformer、掩码自回归和基于学习掩码的预训练模型适配同时存在。
  • 监督和评测目标不同：有的优化视觉质量与速度，有的通过人类偏好或DPO优化物理合理性，有的优化可验证的空间推理。
  • 缩放重点不同：有的缩放模型和异构数据，有的提升实时生成速度，而测试时缩放的证据仍不一致。
  • 部署假设不同：方法对预训练模型参数、动作标注数据、偏好数据或基准专用验证器的访问条件要求不同。

面向机器人想象的生成式视频世界模型

学习视觉前向模型，根据语言和其他条件信号合成未来帧或视频计划以支持机器人执行。

尚未覆盖：泛化受限于已见原语组合；真实机器人执行证据不完整，长时域持续性尚未充分探索。

研究共性

  • 世界模型被视为视觉未来预测、规划与交互的共同基础，而不仅是视频生成器。
  • 辅助条件结构相比单一生成模型能够提升可控性和组合泛化能力。
  • 长时域时间一致性和持久动态被认为是生成式世界模拟的核心挑战。
  • 评测应从视觉质量扩展到控制性能、闭环行为和场景状态一致性。

关键差异

  • 表示层面的分歧：有的工作将生成分解为低级原语，有的采用统一潜在/全局状态或多模态 RGB-D 表示。
  • 条件与监督信号不同：语言驱动分解、自我运动和姿态控制、目的地加潜在个性、持续实体监控等提供了不同的归纳偏置。
  • 评测目标不同：物理机器人学习、自动驾驶仿真、视线外视频基准和可控未来帧预测尚未在同一框架下兼容。

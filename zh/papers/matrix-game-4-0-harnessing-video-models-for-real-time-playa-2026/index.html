深度分析

创新点

  • Separates game execution from visual generation through an executable game harness, with a lightweight game engine maintaining persistent world state and executing interaction rules.
  • Introduces Matrix-Game 4.0 as the first system built on the executable-harness design.
  • Uses a multimodal coding agent to translate player ideas into game code and dynamic scene captions.
  • Uses an autoregressive video renderer conditioned on dynamic captions and memory references to convert engine-rendered low-poly proxies into detailed visuals.
  • Trains the renderer on aligned low-poly and high-fidelity video pairs and distills it into a causal generator that produces four-frame chunks with one or two denoising steps.
  • Enables natural-language creation and modification of scenes and gameplay, with code, model weights, and low-poly game assets released.

方法

Matrix-Game 4.0 uses a lightweight game engine for world state and rules, a multimodal coding agent for game code and dynamic captions, and an autoregressive video renderer that turns low-poly proxy frames into detailed visuals. The renderer is trained on aligned low-poly and high-fidelity video pairs and distilled into a causal generator producing four-frame chunks with one or two denoising steps. Evaluation reports 480p gameplay performance on NVIDIA RTX5090, RTX5080, and RTX5070Ti, measuring frames per second, key-press-to-display latency, and peak GPU memory.

关键结果

Matrix-Game 4.0 achieves 480p, 60 FPS gameplay on a single NVIDIA RTX5090 with 112 ms key-press-to-display latency. Single-step generation reaches 83 FPS steady-state throughput with 18.2 GiB peak GPU memory; with fixed prompts, throughput reaches 67 FPS on RTX5080 and 58 FPS on RTX5070Ti, and customizable shooter and driving games are demonstrated.

深度分析

创新点

  • Delta Latent Transition Model (Delta-LTM) predicts action-induced latent feature changes and adds them to the current latent state instead of directly predicting the next latent state.
  • Interaction-aware Latent Alignment constructs counterfactual interaction regions and supervises interaction-related latent changes to reduce object interpenetration and excessive deformation.
  • DeltaWorld is presented as a physically consistent interactive world simulator for robotic manipulation across multiple robot embodiments and tasks.

方法

DeltaWorld uses action-conditioned latent increment learning, where the Delta-LTM predicts action-induced latent feature changes and adds them to the current latent state to produce the next state. Interaction-aware Latent Alignment constructs counterfactual interaction regions to supervise interaction-related latent changes. The method is evaluated on the IWS manipulation benchmark and a self-collected cross-robot dataset, using FVD and LPIPS metrics relative to the IWS baseline.

关键结果

On the cross-robot dataset, DeltaWorld reduces FVD by 46.6% and LPIPS by 31.1% relative to the IWS baseline, indicating improved long-horizon action-conditioned video prediction.

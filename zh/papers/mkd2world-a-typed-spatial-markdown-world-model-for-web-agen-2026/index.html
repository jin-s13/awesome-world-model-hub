深度分析

创新点

  • 类型化空间Markdown（TSM）：一种Markdown风格的文本状态表示，联合编码界面布局、UI语义和显式位置
  • AtomBlock-WebUI数据集：通过向HTML注入元素类型标签并提取渲染后的边界框，构建了具有精确块级和原子级标注的数据集
  • MKD2World：一种两阶段训练的桌面Web世界模型，用于当前状态描述和动作条件下的下一状态预测
  • 推理时的提炼步骤：解释预测状态并提取与任务相关的证据以选择动作

方法

作者提出类型化空间Markdown（TSM），根据空间关系在块级和原子级序列化桌面Web界面。他们通过向HTML注入元素类型标签并在渲染后直接提取边界框来构建AtomBlock-WebUI数据集，以训练截图到TSM的渲染器。MKD2World分两阶段训练，分别用于当前状态描述和动作条件下的下一状态预测；推理时，Web智能体按需查询该模型，并执行提炼步骤以提取与任务相关的证据。

关键结果

MKD2World-9B在域外测试集上取得EleF1分数26.50，比GPT-5.6-Sol（14.98）高出11.52分。在Online-Mind2Web任务中，MKD2World-9B将Qwen3.5-35B Web智能体的成功率从22.94%提升至37.61%。

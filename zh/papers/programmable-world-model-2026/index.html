深度分析

创新点

  • Programmable World Model 框架，将世界状态演化与视觉观测生成解耦
  • 将自然语言指令转化为可执行程序，指定实体状态与状态转换规则
  • 轻量级引擎维护显式、持久化的全局世界状态，包括屏幕外实体和非视觉属性
  • 状态增强的3D有向边界框 (OBB) 作为中间表示，确定性编译为像素对齐的时空条件信号，用于预训练视频模型
  • 用于评估可编程世界模型的 CombatStateBench 基准

方法

该框架将状态演化与视觉生成解耦：智能体将自然语言指令转化为可执行程序，轻量级引擎执行这些程序以维护显式、持久化的全局世界状态。状态增强的3D有向边界框和目标相机轨迹被确定性编译为像素对齐的时空条件信号，供作为生成渲染器的预训练视频模型使用。评估使用新引入的 CombatStateBench，并报告与现有交互式视频世界模型对比的 Count Accuracy 和 State Accuracy。

关键结果

在 CombatStateBench 上，该方法实现了 94% 的 Count Accuracy 和 98% 的 State Accuracy，显著优于现有交互式视频世界模型，同时支持连贯的长时程生成。

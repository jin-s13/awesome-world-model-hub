深度分析

创新点

  • LLM编码智能体充当遥操作员：给定数据请求和一个校准演示回合，它通过编写场景、专家控制器和成功判官在仿真中重建目标任务。
  • 以真实图像为条件的视频模型将仿真轨迹渲染为照片级逼真视频，且所有相机视角一致地同步生成。
  • DataFarm 输出可直接用于真实场景的数据：与机器人动作标签同步的相机视角，支持直接训练策略并部署到真实机器人。
  • 独立判官在数据收录前对专家控制器和每个渲染回合进行认证。
  • 成本高效的自动化：任务适配平均花费约21美元API调用费用外加5美元渲染合约；额外回合平均0.80美元，且无需机器人和操作员时间。

方法

DataFarm智能体接收数据请求和目标场景中机器人的一个校准演示回合，然后编写仿真场景、专家控制器和成功判官。仿真器提供精确动作，以真实图像为条件的视频模型渲染照片级逼真的多视角视频。策略分别在 DataFarm 数据或遥操作回合上训练，并在五个真实机器人任务上进行了100次试验评估，包括泛化测试和成本比较。

关键结果

仅用DataFarm数据训练的策略与用相同数量遥操作回合训练的策略表现相当，在100次试验中分别获得93次和84次成功；在未见过的桌布和彩色灯光下，前者保持87次成功，而遥操作训练的策略降至46次。一小时三视角数据平均成本约107美元，而中国遥操作报价为117美元，北美仅人工成本就达290美元。

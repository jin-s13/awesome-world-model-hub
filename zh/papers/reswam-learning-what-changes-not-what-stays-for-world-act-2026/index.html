ResWAM: Learning What Changes, Not What Stays, for World-Action Models

深度分析

创新点

  • Visual residual learning that supervises only the feature change from the current frame to the future frame in a frozen DINOv3 space, instead of complete future observations.
  • A residual learning target that yields higher feature rank with richer and more diverse representations of scene changes and spatially concentrates on the robot arm and manipulated objects rather than background.
  • ResWAM, a 2.3B-parameter residual world-action model with a lightweight 0.5B dual-branch DiT that jointly trains an action branch and a residual branch via conditional flow matching.

方法

ResWAM uses a lightweight 0.5B dual-branch DiT within a 2.3B total parameter model, jointly training action and residual branches via conditional flow matching. It supervises only visual residual features from current to future frames in a frozen DINOv3 space rather than complete future observations. The model is evaluated on LIBERO-Plus, RoboTwin 2.0, RoboDojo, and real-robot Open/Put/Stack tasks using success rates, score, latency, and training/inference compute, without robot pretraining beyond benchmark demonstrations.

关键结果

ResWAM achieves top average success rates of 81.1% on LIBERO-Plus, 93.8% on RoboTwin 2.0, and 9.40% success/13.41 score on RoboDojo with the lowest training (2.7-4.0 TFLOPs) and inference compute (1.0-1.4 TFLOPs). On real-robot Open, Put, and Stack tasks it averages 80.0% success, +10.0% over π0.5, at 92.7 ms latency.

局限性

  • The abstract does not state explicit limitations of the proposed ResWAM model.

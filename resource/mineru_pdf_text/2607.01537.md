# Certified World Models as Sensing Clocks: Drift-Aware Deadlines for Active Perception

Hongbo Wang

## Abstract

Certified world models estimate how long their predictions remain valid. We turn this validity horizon into an operational sensing clock: a rule for when an agent should stop coasting and re-sense. Starting from an audited equivariant world model, we derive a deadline for no-sensing intervals and show that deployable deadlines in learned world models must be drift-aware: on-manifold Lyapunov rates alone overestimate coasting validity, while calibrated native rollout-drift envelopes carry the deployed guarantee. On a frozen 3D VN-JEPA model, the resulting clock controls held-out interval-simultaneous certificate violation across seeds and data shards. In a cue-conditioned theorem-bed (a synthetic bench where all schedulers share the exact model, isolating the scheduling rule), the clock remains valid on the deployment distribution and substantially reduces eventful-tail violations relative to exact-mixture expected-belief scheduling at matched sensing budget. We also report limits: in the short-horizon frozen VN-JEPA regime, empirical conformal horizons match the deployed clock on validity and budget, and a partial-reset exploration finds no clean budget-matched advantage for the spectral term. Thus the contribution is a certified sensing-clock primitive and drift-aware deployment method, not a claim that spectral clocks empirically dominate all non-spectral schedulers.

## 1 Introduction

A world model that predicts the future still does not know when its own predictions expire. An agent coasting on open-loop predictions must eventually re-sense; sensing too late forfeits the model’s validity guarantee, sensing too early wastes a scarce budget. Fixed re-planning periods ignore the model’s actual reliability, and purely reactive monitors act only after a residual has already grown. We study the missing primitive:

A certified world model should expose its validity horizon as an operational sensing deadline — a clock that tells the agent when to re-sense. When the certified horizon counts down to zero, the agent stops coasting and senses.

This completes a broader program over certified world models: when to trust a prediction (prior certifiedhorizon work [Wang, 2026]), when to replan, and — here — when to sense. Figure 1 sketches the primitive.

Crowded-field positioning. Active perception, value-of-information, ρ-POMDP planning with guarantees, active-inference / expected-free-energy scheduling, and conformal sensing all schedule observations. Our distinction is narrow and explicit: we contribute the first proactive, analytically-derived certifiedhorizon sensing trigger computed from an audited (equivariant) world model — with the model’s spectral expansion rate as the audit interface the horizon is derived through, and a calibrated drift envelope carrying the deployed guarantee — contrasted against reactive information-gain greedy schedulers, fixed-horizon polling, and conformal residual monitors that lack a predictive-validity certificate. This is a crowded-field diferentiation paper with a new primitive, not an empty-niche claim.

Contributions. We make four positive contributions and state one boundary explicitly.

1. The sensing-clock primitive (certificate = sensing clock): a certified coasting deadline that controls interval-simultaneous certificate violation (§3, Proposition 1, §4).

These results narrow — not refute — the primitive (§6).

## 2 Problem Setup

Coasting intervals. An agent alternates sensing (resetting belief from an observation) and coasting (predicting open-loop with the world model). A coasting interval $\mathcal { T } = ( \tau , \tau ^ { \prime } )$ spans the steps between two senses; $H _ { \mathcal { T } } = \boldsymbol { \tau ^ { \prime } } - \boldsymbol { \tau } - 1$ is its length. The deployed policy is the deadline rule that sets τ <sup>′</sup> given the state at τ .

Interval-simultaneous certificate violation (primary metric). Let $\| \cdot \| _ { c }$ be a certificate norm on the world model’s latent (for VN-JEPA, an irrep/block norm; §3). The pre-registered primary metric is the probability that the coasting prediction error exceeds the certified tolerance $\epsilon _ { \mathrm { c e r t } }$ anywhere in the interval:

$$
\mathrm{ICV} _ {\epsilon} (\pi) = \operatorname * {P r} _ {\mathcal {I}} \left[ \max _ {1 \leq h \leq H _ {\mathcal {I}}} \left\| \hat {z} _ {\tau + h | \tau} - z _ {\tau + h} \right\| _ {\mathcal {C}} > \epsilon_ {\text {cert}} \right], \quad \bar {U} := U _ {0. 9 5} ^ {\text {cluster}} \bigl (\widehat {\mathrm{ICV}} _ {\epsilon} \bigr),\tag{1}
$$

with a cluster-bootstrap upper bound over seeds/episodes (intervals within an episode are not independent); we write $U _ { 9 5 }$ for $\bar { U }$ in tables and results. The pre-registered target is $\bar { U } \le \alpha _ { \mathrm { t a r g e t } } + \delta = 0 . 1 0 + 0 . 0 5 = 0 . 1 5$

Sensing budget. $B ( \pi ) = \mathbb { E } [ \# \mathrm { s e n s e } / T ]$ , the average sensing rate. Comparisons are made at matched budget (thresholds calibrated on a calibration split, frozen, evaluated once on test).

Lead-time (optional; native traces permitting). For safety-critical deployments one also wants actionable lead-time $L _ { \mathrm { s a f e } } = t _ { \mathrm { l a s t - s a f e } } - \tau _ { \mathrm { t r i g g e r } }$ . This requires native hazard / last-safe / intervention semantics, which the VN-JEPA coasting corpus does not contain (§5.4); we test lead-time only on a synthetic bench (§5.3) and explicitly defer the learned-regime lead-time question.

## 3 Method

Spectral horizon (naive). If coasting error grew purely by a local expansion rate λ from a post-sense error $e _ { 0 } ,$ , the deadline would be $T _ { \lambda } ( \epsilon ) \sim \log ( \epsilon / e _ { 0 } ) / \lambda$ . On synthetic linear-Gaussian error dynamics, this oracle spectral horizon provides a calibrated upper bound on interval-simultaneous certificate violation, underlying the mechanism unit tests (§4.1).

Drift-aware correction (load-bearing). On a real frozen world model the on-manifold rate alone overstates the deployable horizon, because the coasting error carries native rollout drift, model bias, and ofmanifold departure that λ does not see. We bound the realized error by

$$
r _ {h} \leq b _ {h} ^ {\mathrm{UCB}} + C e ^ {\lambda h} e _ {0} + \eta_ {h}, \qquad T _ {\mathrm{eq}} = \sup \bigl \{h: b _ {h} ^ {\mathrm{UCB}} + C e ^ {\lambda h} e _ {0} + \eta_ {h} \leq \epsilon_ {\mathrm{cert}} \bigr \},\tag{2}
$$

where $b _ { h } ^ { \mathrm { U C B } }$ is a calibrated native rollout-drift envelope (a held-out high quantile of the coasting error at horizon $h ) , C e ^ { \lambda h } e _ { 0 }$ the audited local-expansion term, and $\eta _ { h }$ a finite-sample slack. The audited Lyapunov rate ranks local on-manifold expansion; deployable coasting validity is governed by the sum of local expansion and native rollout drift.

Proposition 1 (drift-aware interval certificate). Suppose on the calibration distribution the bound $b _ { h } ^ { \mathrm { U C B } } +$ $C e ^ { \lambda h } e _ { 0 } + \eta _ { h }$ dominates the realized coasting error $r _ { h }$ simultaneously over $1 \leq h \leq H$ with probability at least $1 - \alpha$ . Then the deadline $\begin{array} { r } { T _ { \mathrm { e q } } = \operatorname* { s u p } \{ h : \ b _ { h } ^ { \mathrm { U C B } } + C e ^ { \lambda h } e _ { 0 } + \eta _ { h } \leq \epsilon _ { \mathrm { c e r t } } \} } \end{array}$ controls interval-simultaneous certificate violation at level $\alpha ,$ up to the calibration failure probability: $\mathrm { I C V } _ { \epsilon _ { \mathrm { c e r t } } } ( \pi _ { T _ { \mathrm { e q } } } ) \leq \alpha$

Proof sketch. On the event that the bound holds simultaneously, for all $h \leq T _ { \mathrm { e q } }$ we have $r _ { h } \ \leq \ b _ { h } ^ { \mathrm { U C B } } +$ $C e ^ { \lambda h } e _ { 0 } + \eta _ { h } \leq \epsilon _ { \mathrm { c e r t } } ,$ , so no interval-simultaneous violation occurs; the violation event is contained in the calibration-failure event of probability $\leq \alpha$ □

This restates the deployed calibration protocol as a certificate; it makes no claim that λ improves the bound — in the full-resense regime $e _ { 0 } \approx 0$ and the bound is drift-dominated.

Deployed form in the full-resense regime. With full re-sensing the post-sense error $e _ { 0 }$ ≈ 0, so $C e ^ { \lambda h } e _ { 0 }$ vanishes and the deployed deadline reduces to the drift-envelope clock

$$
T _ {\mathrm{drift}} (\epsilon) = \sup \{h: b _ {h} ^ {\mathrm{UCB}} \leq \epsilon_ {\mathrm{cert}} \}.\tag{3}
$$

We confirm this is exactly the deployed deadline on the frozen VN-JEPA (§5.4). Consequently the onmanifold spectrum λ acts as a local-expansion audit / theoretical interface, not an active term in the deployed horizon. (Empirically, audited on-manifold $\lambda \approx 0 . 0 7 ;$ a naive λ-only horizon over-states the deployable horizon by roughly an order of magnitude, while the drift envelope yields the deployed ∼2–3 step horizon.)

Calibration protocol. On VN-JEPA the certificate norm is the per-block normalized maximum over irrep blocks $b , \| e \| _ { \mathcal { C } } = \operatorname* { m a x } _ { b } \| e _ { b } \| _ { 2 } / s _ { b }$ , with per-block scales $s _ { b }$ . The test split is evaluated once with no retuning. The spectral audit is performed on the native on-manifold trajectory (free-iteration of a short-horizon residual predictor produces an of-manifold expansion artifact, $\lambda \approx 3 . 5$ vs the on-manifold $\approx 0 . 0 7$ , and is used only as an of-manifold stress diagnostic).

## 6 Discussion

What is established. (i) A certified sensing-clock primitive that controls interval-simultaneous certificate violation; (ii) a drift-aware deployment method, with the empirical finding that on-manifold λ alone overstates the horizon and the native rollout-drift envelope carries the deployed guarantee; (iii) instantiation on a real frozen 3D VN-JEPA equivariant world model, confirmed across seed and shard; (iv) a reactive-contrast theorem-bed showing expected-belief scheduling under-prices the eventful tail at matched budget.

What is not established. (i) Actionable lead-time over residual-reactive schedulers (Stage 2B null on exact synthetic; not testable on native VN-JEPA traces). (ii) Non-replaceability: in the learned short-horizon regime a non-spectral empirical conformal horizon matches the deployed clock on validity and budget (Stage 2C-V warning). (iii) An empirical edge for the spectral term itself (E0 null). We explicitly do not claim the spectral clock empirically dominates reactive, conformal, or robust schedulers.

When might λ matter? The spectral term is dormant precisely because deployment fully re-senses (e<sub>0</sub> ≈ 0) over short horizons. Regimes that could re-activate it — non-trivial / state-dependent post-sense error (partial sensing), longer coasting horizons, or imperfect-model settings where audited spectra and drift envelopes diverge from empirical conformal calibration — are natural future work. Our partial-reset probe (§5.5) activated the term but found no budget-matched edge, so we present this cautiously.

Why this is still a new primitive. Even where simpler conformal horizons match the deployed clock numerically, the contribution is the framing and method: turning a certified validity horizon into an operational re-sensing deadline, the drift-aware correction that makes it deployable on a real equivariant world model, and the pre-registered reactive-contrast methodology (including the eventful-tail / false-exclusion analysis) under which expected-belief scheduling is shown to under-price tail risk. The certificate-as-clock interfac connecting certified world models to action — is the durable contribution.

Anticipated reviewer questions. Q1 — If a non-spectral conformal horizon reproduces the deployed clock (§5.4), why is this valuable? The deliverable is the primitive, the method, and the methodology — not a number. The certificate-as-clock interface, the drift-aware correction that makes the horizon deployable on a real equivariant world model, and the pre-registered reactive-contrast protocol (eventful-tail / falseexclusion decomposition) stand independently of whether a conformal horizon happens to match the deadline in one regime. Replaceability is demonstrated only on validity and budget, only in the short-horizon fullresense regime, and only against schedulers that themselves lack a predictive-validity certificate; we report it as a warning, not a refutation, and name the regimes where the question reopens. The primitive also has a theoretical identity: in a Gaussian toy the certified clock and the epistemic-threshold scheduler of active inference parameterize the same schedule family, and the deployed drift-aware clock is that family’s calibrated member (Proposition 2, Appendix B).

Q2 — If the deployed clock is drift-only, why keep the spectral / Lyapunov framing? The title foregrounds drift-aware deadlines precisely because the deployed term is the drift envelope. The spectral rate is retained as the derivation and audit interface: it is how a certificate horizon is read of an equivariant world model, it supplies the on- vs of-manifold expansion diagnostic $( \lambda \approx 0 . 0 7$ on-manifold vs ≈ 3.5 of-manifold), and it is the term that partial-sensing or longer-horizon regimes would reactivate $( e _ { 0 } \not \approx 0 )$ . We are explicit (§3, §5.5) that λ is not the deployed active term in the full-resense regime; consistently, the shared certified/epistemic countdown of the Gaussian toy is exactly the spectral horizon $T _ { \lambda }$ (Corollary 1), while the exploratory ablation finds the audited rate mis-states the deployable horizon in opposite directions across regimes (Appendix C)

both facts point to the calibrated envelope as the deployment term and to λ as the derivation interface.

Q3 — Stage 2A only separates from expected-belief MB-EIG; risk-sensitive (MB-CVaR) and robust (MB-WorstCase) schedulers tie. Is the win real? Yes, with a stated scope. In the exact-model limit, risk-sensitive and robust schedulers provably approach the certified clock — MB-WorstCase is essentially the oracle robust reference, so a tie with it is the expected and desirable outcome, not a weakness. The honest claim is narrow: expected-belief (mean-information-gain) scheduling under-prices the eventful tail (0.36 vs 0.16 at matched budget), and the certified clock reaches the robust/risk-sensitive frontier without oracle access to the worst case. Whether the certified clock can separate from CVaR / worst-case once exact-model equivalence breaks is exactly the learned-regime question Stage 2C defers.

## 7 Related Work

We position the primitive against five neighboring families; the carve is narrow — we make the validity horizon itself the trigger — and we do not claim to outperform these families in general.

Active sensing / value-of-information / POMDP with guarantees. Measurement simplification in ρ-POMDPs with performance guarantees [Yotam and Indelman, 2023] schedules and simplifies observations by belief-space value while bounding the loss. We difer by deriving a proactive deadline from an audited world-model validity horizon rather than from online belief-space planning: the trigger is certified coasting validity, not task value or belief utility.

Reactive information-gain / entropy scheduling. Information-driven active perception selects sensor queries by the k-step conditional entropy of future-state safety under a query budget [Udupa and Fu, 2026]. These schedulers act on predicted uncertainty as it accrues. Our Stage 2A shows a separation from expectedbelief (mean-information-gain) scheduling (MB-EIG) specifically, on eventful-tail validity at matched budget; we do not claim a separation from all reactive schedulers — risk-sensitive and robust variants track our clock in the exact-model limit (§5.2).

Conformal / calibrated uncertainty. Conformal prediction gives distribution-free, finite-sample coverage [Angelopoulos and Bates, 2021] and underlies a strong non-spectral baseline. We are explicit that conformal horizons are strong here: in the frozen VN-JEPA short-horizon regime, an empirical conformal horizon matches our deployed clock on validity and budget (Stage 2C-V, §5.4). Our contribution is the certificate-as-clock framing and protocol, not numerical superiority over a conformal horizon in this regime; the conformal comparison is reported as a warning, not a defeat.

Active inference / expected free energy. Belief-space control via active inference schedules measurements by an epistemic (expected-free-energy) objective [Sargun et al., 2026]. Such schedulers are objectivedriven and, in this line, domain-specific and certificate-free; ours is a certificate-grounded interval guarantee rather than a free-energy heuristic. The bridge is in fact formal: in a Gaussian toy the two trigger rules parameterize the same schedule family, with the deployed drift-aware clock as its calibrated member (Ap pendix B).

World-model verification and certified world models. A growing line verifies imagined rollouts or controls robustly: closed-loop world-model verification [Geng et al., 2026], event-verified world models [Wang et al., 2026], and robust MPC for certified manipulation [Li et al., 2026]. This work builds on a certifiedhorizon line that supplies the faithful-certificate and prediction-horizon machinery [Wang, 2026]; we turn that horizon into an operational re-sensing deadline. Versus detector-style residual monitors: a detector alarms after seeing a residual, our clock senses before one arrives. Table 6 (Appendix F) maps the families.

## B The Sensing Countdown as a Calibrated Epistemic-Threshold Scheduler

This appendix gives the sensing-clock primitive a theoretical identity: in a Gaussian toy, the certified clock and the epistemic (expected-information-gain) scheduler of active inference are the same family of sensing schedules, and the deployed drift-aware clock is that family’s calibrated member. The result is deliberately narrow (Remarks 2–3); it does not rescue the empirical replaceability boundary of §5.4–5.5.

Setup. A scalar latent coasts as $z _ { h + 1 } = a z _ { h } + w _ { h } , w _ { h } \sim \mathcal { N } ( 0 , \sigma _ { w } ^ { 2 } )$ . After a sense the agent holds $b _ { 0 } =$ $\mathcal { N } ( \mu _ { 0 } , P _ { 0 } )$ and propagates open-loop, $b _ { h } \ = \ N ( \mu _ { h } , P _ { h } )$ with $P _ { h + 1 } = a ^ { 2 } P _ { h } + \sigma _ { w } ^ { 2 }$ . A sense at h returns $o _ { h } = z _ { h } + v _ { h } , v _ { h } \sim \mathcal { N } ( 0 , \sigma _ { o } ^ { 2 } )$ . Under model correctness the coasting error satisfies $e _ { h } \sim \mathcal { N } ( 0 , P _ { h } )$ , so with $q _ { \alpha }$ the standard-normal $( 1 - \alpha / 2 )$ -quantile the certified clock triggers at

$$
\tau_ {\mathrm{cert}} (\epsilon) = \inf \{h \geq 1: q _ {\alpha} ^ {2} P _ {h} > \epsilon^ {2} \},\tag{4}
$$

while the epistemic-threshold scheduler triggers when the expected information gain of sensing, $\operatorname { I G } ( h ) =$ $\begin{array} { r } { I ( z _ { h } ; o _ { h } ) = \frac { 1 } { 2 } \ln \bigl ( 1 + P _ { h } / \sigma _ { o } ^ { 2 } \bigr ) } \end{array}$ , first exceeds a threshold c:

$$
\tau_ {\mathrm{EFE}} (c) = \inf \{h \geq 1: \operatorname{IG} (h) > c \}.\tag{5}
$$

Proposition 2 (threshold equivalence). Fix $\alpha \in ( 0 , 1 )$ and $\sigma _ { o } ^ { 2 } > 0$ , and let $\begin{array} { r } { c ( \epsilon ) = \frac { 1 } { 2 } \ln \bigl ( 1 + \epsilon ^ { 2 } / ( q _ { \alpha } ^ { 2 } \sigma _ { o } ^ { 2 } ) \bigr ) } \end{array}$ . Then for every variance path $( P _ { h } ) _ { h \geq 1 } \ - \ r e g a r d l e s s$ of the dynamics generating $i t \_ - \tau _ { \mathrm { E F E } } ( c ( \epsilon ) ) = \tau _ { \mathrm { c e r t } } ( \epsilon )$ , and $\epsilon \mapsto c ( \epsilon )$ is a strictly increasing bijection of (0, ∞) onto itself. Certified tolerances and epistemic thresholds therefore parameterize the same family of sensing schedules.

Proof. For each h: $\mathrm { I G } ( h ) > c ( \epsilon ) \iff \ln ( 1 + P h / \sigma _ { o } ^ { 2 } ) > \ln ( 1 + \epsilon ^ { 2 } / ( q _ { \alpha } ^ { 2 } \sigma _ { o } ^ { 2 } ) ) \iff P _ { h } > \epsilon ^ { 2 } / q _ { \alpha } ^ { 2 } \iff q _ { \alpha } ^ { 2 } P _ { h } > \epsilon ^ { 2 }$ by strict monotonicity of x 7→ ln $( 1 + x / \sigma _ { o } ^ { 2 } )$ . The trigger events coincide at every h, hence so do the firstcrossing times (including $\tau = \infty$ on both sides). Bijectivity is immediate. □

Corollary 1 (shared countdown = the spectral horizon). Under the expanding recursion $( a ^ { 2 } > 1 ) , P _ { h } =$ $a ^ { 2 h } \big ( P _ { 0 } + \kappa \big ) - \kappa$ with $\kappa = \sigma _ { w } ^ { 2 } / ( a ^ { 2 } - 1 )$ is strictly increasing, so both schedulers reduce to one deterministic countdown whose deadline is, up to the additive ofset κ,

$$
T (\epsilon) \approx \frac {1}{\lambda} \ln \frac {\epsilon}{q _ {\alpha} \tilde {e} _ {0}}, \quad \lambda = \ln a, \quad \tilde {e} _ {0} = \sqrt {P _ {0} + \kappa},\tag{6}
$$

i.e. exactly the spectral horizon $T _ { \lambda } ( \epsilon ) \sim \ln ( \epsilon / e _ { 0 } ) / \lambda$ of ${ \ S } \mathcal { B } .$

Remark 1 (the deployed clock is the calibrated member). Both sides of Proposition 2 take the model-trusting variance $P _ { h }$ as input. Under model error the realized coasting error is no longer $\mathcal { N } ( 0 , P _ { h } )$ : the epistemic scheduler keeps triggering on the model’s $P _ { h }$ (mis-timed), whereas the deployed clock replaces $q _ { \alpha } \sqrt { P _ { h } }$ by the held-out calibrated drift envelope $b _ { h } ^ { \mathrm { U C B } } ~ ( \ S 3 )$ ). The two schedules then difer by exactly that calibration correction: deployed drift-aware clock = epistemic trigger + distribution-free calibration.

Remark 2 (vector / block structure). In higher dimension the epistemic term is $\frac { 1 } { 2 }$ ln de $( I + P _ { h } \Sigma _ { o } ^ { - 1 } ) \mathrm { ~ - ~ a ~ }$ sum over spectral directions — while the block certificate norm max $\| e _ { b } \| / s _ { b }$ is a max functional. The two threshold families coincide exactly only in the scalar/isotropic case; in general they are directionally aligned (each bounds the other up to block-count factors) but not identical.

Remark 3 (scope). The equivalence concerns the epistemic-only, greedy-threshold form of expected-freeenergy scheduling on a fixed observation channel — not full POMDP planning, and not the pragmatic/risk terms. It confers a theoretical identity on the primitive; it does not contradict the empirical findings that a non-spectral conformal horizon matches the deployed clock on validity and budget in the short-horizon regime (§5.4–5.5).

## D Stage 2A: The Exact Switch-Time Mixture MB-EIG Baseline

Stage 2A’s honesty hinges on the reactive baseline being the strongest expected-belief scheduler available in the theorem-bed, so we record its exact form.

Hazard model. Each coasting interval carries a latent risk type $u \in \{ S , R \}$ emitting a noisy pre-interval cue c with posterior $p _ { R } ( c )$ . In a risky interval the mode switches from benign to expansive dynamics at a hidden time and the switch is absorbing:

$$
\operatorname * {P r} (m _ {\tau + h} = \mathrm{expansive} | u = R) = 1 - (1 - p _ {\mathrm{sw}}) ^ {h}.\tag{7}
$$

Exact mixture. Because the switch is absorbing, the branch space at horizon h is not $2 ^ { h }$ paths but $h { + 1 } { : }$ “switch first occurred at step $s ^ { \mathfrak { w } } \ ( s = 1 , \ldots , h )$ plus “no switch by $h ^ { \prime \prime }$ . MB-EIG therefore evaluates its expected-entropy objective on the exact mixture

$$
J _ {\exp} (h, c) = \sum_ {s = 1} ^ {h} \operatorname * {P r} (s \mid c) H \bigl (P _ {h} ^ {(s)} \bigr) + \operatorname * {P r} (\text { no   switch   by } h \mid c) H \bigl (P _ {h} ^ {(0)} \bigr),\tag{8}
$$

with absorbing-hazard branch weights

$$
\operatorname * {P r} (s \mid c) = p _ {R} (c) \left(1 - p _ {\mathrm{sw}}\right) ^ {s - 1} p _ {\mathrm{sw}}, \quad \operatorname * {P r} (\text { no   switch   by } h \mid c) = 1 - p _ {R} (c) \bigl (1 - \left(1 - p _ {\mathrm{sw}}\right) ^ {h} \bigr),\tag{9}
$$

where $P _ { h } ^ { ( s ) }$ propagates s−1 benign steps followed by expansive steps and $P _ { h } ^ { ( 0 ) }$ is all-benign. The risk-sensitive baseline (MB-CVaR) computes $\mathrm { C V a R } _ { \beta }$ on the same branch distribution $\{ \operatorname* { P r } ( s \mid c ) \}$

Why moment matching is not allowed as the primary baseline. The single-covariance recursion $P _ { h + 1 } ^ { \mathrm { m i x } } = ( 1 - \pi _ { h } ) A _ { b } P _ { h } ^ { \mathrm { m i x } } A _ { b } ^ { \top } + \pi _ { h } A _ { e } P _ { h } ^ { \mathrm { m i x } } A _ { e } ^ { \top } + Q$ , with $\pi _ { h } = p _ { R } ( c ) ( 1 - ( 1 - p _ { \mathrm { s w } } ) ^ { h } )$ , collapses the branch distribution to its moments and thereby weakens the reactive baseline exactly where the contrast lives (the expansive tail). It is used only as a speed/diagnostic fallback. Consequently the Stage 2A separation (§5.2) is against the exact-mixture — i.e. the strongest — expected-belief scheduler, and the residual-tail decomposition attributes Eq-spec’s own leakage to its pre-registered false-exclusion mass rather than to deadline failure.

## E Stage 2B: Bench Geometry, and Why Lead-Time Separation Is Structurally Hard in 1D

Bench. A 1D point system $p _ { t + 1 } = p _ { t } + v _ { t } + \mathscr { N } ( 0 , \sigma _ { p } ^ { 2 } ) , v _ { t + 1 } = v _ { t } + u _ { t } + \mathscr { N } ( 0 , \sigma _ { v } ^ { 2 } )$ , with an irreversible failure set $\{ p \ge p _ { \mathrm { f a i l } } \}$ and a hazard zone [p , p ). A PD controller drives the cart through the hazard toward $p _ { \mathrm { g o a l } } > p _ { \mathrm { f a i l } }$ , so every nominal episode is a genuine approach-to-hazard; $t _ { \mathrm { l a s t } }$ is the last step at which max-braking still avoids failure, and $L _ { \mathrm { s a f e } } = t _ { \mathrm { l a s t } } - \tau _ { \mathrm { t r i g g e r } }$ . The Stage 2B configuration (§5.3) uses matched budget $B \approx 0 . 5 0$ and $t _ { \mathrm { l a s t } } \approx 2 \substack { - 4 }$

Post-hoc structural analysis (no additional contrast was run). A follow-up geometry search for a low-budget variant $( B \le 0 . 2 0 , t _ { \mathrm { l a s t } } \in [ 6 , 1 2 ]$ , deadline diversity $T _ { \mathrm { h i g h } } / T _ { \mathrm { l o w } } \geq 3$ , late residual onset) terminated at its pre-declared gate: the gates could not be satisfied simultaneously in this bench family. The diagnosis is structural rather than a tuning failure, and it sharpens the reading of the Stage 2B null:

1. Homogeneous starts make the null a theorem. With a common start state, the certified deadline $T _ { \mathrm { s p e c } } ( z _ { 0 } )$ and a uniform poller’s period are both episode-constant; at matched budget they coincide step-for-step, so no a-priori deadline can separate from constant-period polling. The near-identical lead-time rates of §5.3 (0.955 vs 0.957) are the expected outcome, not a coincidence.

2. Heterogeneous starts trade the two required structures against each other. In this family the certified deadline, the braking deadline, and hazard entry are nearly collinear — all shifts of arrival time: $T _ { \mathrm { s p e c } } \approx t _ { \mathrm { e n t r y } } + \Delta , t _ { \mathrm { l a s t } } \approx t _ { \mathrm { e n t r y } } + w$ . Creating deadline diversity (spread in arrival times) simultaneously widens the slow tail’s braking window w, which restores exactly the early-onset structure that lets reactive and periodic baselines succeed. In a six-round calibration sweep the diversity gate never exceeded 2.0× (target 3×) while the late-onset gate peaked at 0.69 (target 0.8).

Consequence. The lead-time question for certified sensing clocks is not settled negatively by §5.3 alone; rather, this bench family cannot pose it. Establishing (or refuting) an actionable lead-time advantage requires hazard structure in which certified deadlines and braking deadlines decouple — multiple hazard sites, nonmonotone approaches, or higher-dimensional dynamics. We record this as an open bench-design problem.

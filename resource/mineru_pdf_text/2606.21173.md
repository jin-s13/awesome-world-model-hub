## Abstract

Model-based and model-free reinforcement learning are traditionally viewed as separate paradigms: instead of learning a model of the transition kernel P , modelfree agents typically estimate value functions tied to a specific policy and reward. In this paper, we challenge this dichotomy by proving that value-based agents trained on a sufficiently rich set of reward functions, e.g. using goal-conditioned RL, implicitly encode a unique and accurate world model. To extract this model in practice, we introduce P -learning, an inverse analogue to Q-learning that samples from an agent’s Q-values, policies and rewards to decode its internal model of the environment. We then provide sufficient conditions on the type and number of goals for which agents encode the true kernel P , covering both stochastic and deterministic MDPs over finite or continuous state spaces. Even when our assumptions are violated, we empirically demonstrate that agents trained on a handful of reward functions encode accurate dynamics in Reacher, MountainCar and stochastic variants of FourRooms. Surprisingly, we find that policies trained exclusively on a Reacher agent’s implicit world model are quasi-optimal on outof-distribution, velocity-based goals despite position-only training – suggesting that agents contain hidden generalisation capabilities and providing a new lens into the connection between model-based, model-free, and goal-conditioned RL.

## 1 Introduction

The model-free paradigm of reinforcement learning (RL) has proven effective in training highly capable agents across a variety of domains [1, 2, 3], sidestepping the challenges associated with modelling complex world dynamics [4, 5]. However, the policies or value functions learnt by such agents are tied to reward functions, making it difficult to repurpose them for new tasks without additional data, or interpret what they understand of the world – as opposed to what they value. In general, distinct world models (transition kernels) can give rise to identical value functions and optimal policies, an obstacle formalised as the value equivalence problem [6, 7].

For example, in a deterministic maze with a binary-reward goal, the optimal value of a state is $\gamma ^ { d }$ where $\gamma$ is the discount factor and d is the minimal distance to the goal (measured by path-length). In particular, $Q \cdot$ -values encode whether an action moves the agent closer to the goal, but do not pin down the state that an action leads to, i.e. the transition kernel, if there are equidistant states. This underdeterminacy implies that model-free agents do not uniquely encode the environment they inhabit, suggesting a fundamental divide between model-free and model-based RL.

However, agents are increasingly trained on a variety of goals – e.g. via successor features [8, 9], forward-backward learning [10] or goal-conditioned RL (GCRL) [11] – which may provide additional constraints on the underlying dynamics. This raises the core question motivating this paper:

## When do model-free agents implicitly encode an accurate model of their environment?

We hypothesise that value-based agents trained on a sufficiently rich set of goals implicitly learn a unique model of the world dynamics, even in stochastic and continuous MDPs, and that this model is accurate insofar as Q-values are accurate. Taking GCRL as the broader framework for agents trained on goals parameterised by arbitrary reward functions, our work makes three contributions to test this hypothesis bridging model-free, model-based and goal-conditioned RL.

Methodologically, we introduce P -learning (Section 3), an analogue to Q-learning illustrated in Figure 1. Instead of iteratively updating value estimates for a fixed environment, P -learning updates a candidate world model (WM) to be progressively more consistent with fixed value functions, effectively inverting the Bellman equation. We make this precise by proving that tabular P -learning converges to a solution involving the Moore-Penrose pseudo-inverse (Theorem 1). Our algorithm enables the efficient extraction of an implicit WM from a collection $( Q _ { g } , \pi _ { g } , r _ { g } ) _ { g \in \mathcal { G } }$ of Q-functions, policies and reward functions – noting that policies are usually induced by Q-functions via argmax or softmax, so $( Q , \pi , r )$ is often equivalent to (Q, r) in practice.

Theoretically, we prove sufficient conditions on the goals and reward functions for which P is uniquely identifiable from $Q \cdot$ -values (Section 4), breaking value equivalence. Four regimes emerge: in deterministic finite MDPs, a single generic goal suffices (Theorem 2); in stochastic finite MDPs, goals must span the state space (Theorem 3), with tight error bounds in both regimes when Q-values are ϵ-approximate. In the deterministic continuous case, a finite number of goals is, surprisingly, sometimes sufficient (Theorems 8 and 9). In stochastic continuous MDPs, identifiability is driven by coverage instead of count: a goal set with non-empty interior for Gaussian rewards (Theorem 6), or covering the state space for indicator rewards (Theorem 7). Taken together, our results show that methods like GCRL can bridge model-free and model-based RL, with the collection $( Q _ { g } , \pi _ { g } , r _ { g } ) _ { g \in \mathcal { G } }$ becoming informationally equivalent to the kernel $P$ when $\mathcal { G }$ is sufficiently rich.

Empirically, we show that P -learning is highly effective in extracting accurate world models from agents, even with very few goals (Section 5). We validate our finite-MDP theory across three increasingly stochastic variants of FourRooms (deterministic, windy and teleporting), with $| \mathcal { G } | = 1$ $| \mathcal { G } | = 4$ and $| \mathcal { G } | = 2 0$ goals respectively sufficient for quasi-perfect recovery. In Reacher, with only $| \mathcal { G } | = 4$ goals despite a continuous state space, we find that implicit WMs are even accurate over variables that rewards never directly depend on. Surprisingly, this accuracy transfers to nearoptimal planning inside the WM for a range of out-of-distribution goals, including reaching specific angular velocities, despite position-only training. We study these “implicit generalisation capabilities” in MountainCar and show that inverting the setup, by training on velocity-based goals, yields a near-identical WM – revealing that agents with widely different objectives can secretly encode similar models. Finally, we identify a strong correlation (Spearman $\rho = 0 . 9 8 )$ between an agent’s performance and the accuracy of its internalised WM, suggesting that GCRL is an implicitly hybrid method linking model-free and model-based RL. Discussion of related work is deferred to Section 6.

## 2 Background

Goal-Conditioned RL (GCRL). We consider goal-augmented MDPs $\mathcal { M } = ( \mathcal { S } , \mathcal { A } , \mathcal { G } , P , \mu , r , \gamma )$ with finite or continuous state space $s ,$ , arbitrary action space A and goal set G, Markov transition kernel $P : \mathcal { S } \times \mathcal { A }  \Delta ( \mathcal { S } )$ , initial state distribution $\mu \ \in \ \Delta ( S )$ , discount factor $\gamma \in \ [ 0 , 1 )$ and goal-conditioned reward function $r : \mathcal { S } \times \mathcal { G } \to \mathbb { R }$ . As in early GCRL literature [11], goals $g \in { \mathcal { G } }$ are specified by arbitrary functions of the state, as opposed to exclusively indicator goals defined by $r ( s , g ) = \delta _ { g s }$ , also called goal states [12, 13]. Denoting the return of a trajectory $\tau = ( s ^ { t } , a ^ { t } ) _ { t \geq 0 }$ with respect to $g$ by $\begin{array} { r } { \dot { R ( \tau , g ) } : = \sum _ { t > 0 } \gamma ^ { t } r ( s ^ { t + 1 } , g ) } \end{array}$ , the objective of GCRL is to learn a goal-conditioned policy $\pi : { \mathcal { S } } \times { \mathcal { G } } \to \Delta ( { \mathcal { A } } )$ such that each $\pi _ { g } : = \pi ( \cdot , g )$ maximises the objective $J _ { g } ( \pi ) : = \mathbb { E } _ { \tau \sim \pi _ { q } } [ R ( \tau , g ) ]$ , where $\tau \sim \pi _ { g }$ is shorthand for independently sampling $s _ { 0 } \sim \mu ,$ $a _ { t } \sim \pi ( s _ { t } , g ) , s _ { t + 1 } \sim P ( s _ { t } , a _ { t } )$ for all t. The value and action-value functions are defined by

$$
V ^ {\pi} (s, g) := \mathbb {E} _ {\tau \sim \pi_ {g}} [ R (\tau , g) \mid s ^ {0} = s ] \text {and} Q ^ {\pi} (s, a, g) := \mathbb {E} _ {\tau \sim \pi_ {g}} [ R (\tau , g) \mid s ^ {0} = s, a ^ {0} = a ].
$$

Our finite-MDP results extend to goals with arbitrary termination indicators [14], while some of our continuous-MDP results include explicit termination conditions; see Appendix D.1 for details.

Q-Iteration. For a fixed goal-augmented MDP, we define $\mathcal { Q } : = \{ Q : \mathcal { S } \times \mathcal { A } \times \mathcal { G }  \mathbb { R } \}$ as the space of action-value functions, and the goal-conditioned Bellman operators $T ^ { \pi } , T ^ { \star } : \mathcal { Q }  \mathcal { Q }$ as

$$
\begin{array}{l} \mathcal {T} ^ {\pi} (Q) (s, a, g) := \mathbb {E} _ {s ^ {\prime} \sim P (s, a), a ^ {\prime} \sim \pi (s ^ {\prime}, g)} \left[ r (s ^ {\prime}, g) + \gamma Q (s ^ {\prime}, a ^ {\prime}, g) \right], \\ \mathcal {T} ^ {\star} (Q) (s, a, g) := \mathbb {E} _ {s ^ {\prime} \sim P (s, a)} \left[ r (s ^ {\prime}, g) + \gamma \sup _ {a ^ {\prime} \in \mathcal {A}} Q (s ^ {\prime}, a ^ {\prime}, g) \right], \end{array}
$$

with the corresponding Bellman and Bellman optimality equations ${ \mathcal { T } } ^ { \pi } ( Q ^ { \pi } ) = Q ^ { \pi } , { \mathcal { T } } ^ { \star } ( Q ^ { \star } ) = Q ^ { \star }$ The aim of value-based methods is to approximate a solution to the Bellman optimality equation. A classical approach, known as Q-iteration [1, 15], starts with an initial guess $Q _ { 0 }$ and iteratively applies the Bellman operator $Q _ { n + 1 } : = T ^ { \star } ( Q _ { n } )$ ) to get a sequence $( Q _ { n } ) _ { n \in \mathbb { N } }$ converging to a fixed-point. In practice, with a parametric family $\theta \mapsto Q _ { \theta } \in \mathcal { Q }$ , we fix a reference distribution $\dot { d } \in \Delta ( S \times \bar { \mathcal { A } } \times \mathcal { G } )$ $\mathrm { e . g }$ . induced by an exploration policy, and measure fixed-point violation via the Bellman residual $\mathcal { L } ( \theta , \theta _ { n } ) : = \lVert \dot { T } ^ { \star } ( Q _ { \theta _ { n } } \bar { ) } - Q _ { \theta } \rVert _ { d } ^ { 2 }$ , where $\begin{array} { r } { \| X \| _ { d } ^ { 2 } : = \frac { 1 } { 2 } \mathbb { E } _ { d } [ X ^ { 2 } ] } \end{array}$ . One can then update $\theta _ { n }$ by minimising $\mathcal { L } ( \theta , \theta _ { n } )$ with respect to θ. Writing $\delta _ { \theta , \theta _ { n } } : = T ^ { \star } ( \mathsf { \tilde { Q } } _ { \theta _ { n } } ) \dot { ) } - \mathsf { \tilde { Q } } _ { \theta }$ for the temporal difference error, the residual is usually minimised using gradient-based methods, with parameter updates driven by

$$
\nabla_ {\theta} \mathcal {L} (\theta , \theta_ {n}) = - \mathbb {E} _ {(s, a, g) \sim d} \left[ \delta_ {\theta , \theta_ {n}} (s, a, g) \nabla_ {\theta} Q _ {\theta} (s, a, g) \right].
$$

Notably, this does not correspond to gradient descent on a fixed objective; the target ${ \mathcal { T } } ^ { \star } ( Q _ { \theta _ { n } } )$ depends on current parameters, so $\bar { \mathcal { L } } ( \boldsymbol { \theta } , \bar { \boldsymbol { \theta } _ { n } } )$ shifts with each iteration. Estimating this expectation using environment samples yields a family of temporal difference (TD) algorithms [16] including Q-learning [17, 18], DQN [2, 19] and PQN [20], adapted here with goal-conditioning. These differ in the iterative optimization method, choice of sampling distribution $d ,$ number of steps performed on $\mathcal { L } ( \theta , \theta _ { n } )$ before updating $\theta _ { n } .$ , parametric family, and resulting convergence guarantees.

## 3 P -Learning

While Q-iteration treats the kernel $P$ as fixed and searches for a function $Q ^ { * }$ that satisfies ${ \mathcal { T } } ^ { * } ( Q ^ { * } ) =$ $Q ^ { * }$ , we consider the inverse problem of extracting an “internal” model $P ^ { \star }$ of the environment from a fixed agent with goal-conditioned Q-values, policy π, and known reward function r. Formally, let $\mathcal { P } : = \mathcal { \{ S \times A }  \stackrel { \smile } { \to } \Delta ( { \mathcal { S } } ) \}$ be the set of transition kernels, and consider a parametric family $\varphi \mapsto P _ { \varphi } \in { \mathcal { P } }$ . We write $\dot { T } _ { \varphi } ^ { \pi } = T _ { P _ { \varphi } } ^ { \pi }$ for the corresponding Bellman operator, making explicit the dependence on WM parameters $\varphi .$ Our guiding observation is that for an agent $( Q , \pi )$ , a model $P _ { \varphi }$ satisfying the Bellman equation $\stackrel { . } { T _ { \varphi } ^ { \pi } } ( Q ) \stackrel { - } { = } Q$ is compatible with the agent’s behavior, and may thus be viewed as (one possible) subjective belief of the agent about the environment.

A natural objective is therefore to minimise the Bellman residual $\mathcal { L } ( \varphi ) = \| \mathcal { T } _ { \varphi } ^ { \pi } ( Q ) - Q \| _ { d } ^ { 2 } = : \| \delta _ { \varphi } \| _ { d } ^ { 2 }$ this time with respect to $\varphi .$ . We call this P -learning. If $P _ { \varphi }$ is differentiable, we can minimise this loss with gradient-based methods, where the direction of parameter updates is driven by

$$
\nabla_ {\varphi} \mathcal {L} (\varphi) = \mathbb {E} _ {(g, s, a) \sim d} \left[ \delta_ {\varphi} (s, a, g) \nabla_ {\varphi} \mathcal {T} _ {\varphi} ^ {\pi} (Q) (s, a, g) \right].
$$

Unpacking this, we define the TD estimate $\hat { \delta } _ { \varphi } ( s , a , g , s ^ { \prime } , a ^ { \prime } ) : = r ( s ^ { \prime } , g ) + \gamma Q ( s ^ { \prime } , a ^ { \prime } , g ) - Q ( s , a , g )$ and prove in Appendix A that under standard regularity assumptions,

$$
\nabla_ {\varphi} \mathcal {L} (\varphi) = \mathbb {E} _ {g, s, a, s ^ {\prime}, a ^ {\prime}} \left[ \delta_ {\varphi} \hat {\delta} _ {\varphi} \nabla_ {\varphi} \log P _ {\varphi} (s ^ {\prime} | s, a) \right],
$$

where $( s , a , g ) \sim d$ and $s ^ { \prime } \sim P _ { \varphi } ( s , a ) , a ^ { \prime } \sim \pi ( s ^ { \prime } , g )$ . For large or continuous state spaces, the gradient can instead be estimated via the reparameterisation trick [21, 22]. Intuitively, while $Q \cdot$ learning finds a Q-function $Q _ { \theta ^ { \star } }$ that is most consistent with the MDP (best satisfies the Bellman equation $\mathcal { T } ^ { \star } [ Q _ { \theta ^ { \star } } ] = Q _ { \theta ^ { \star } } )$ , P -learning finds a model $P _ { \varphi } ,$ ⋆ that is most consistent with a Q-function (best satisfies the Bellman equation $\breve { T _ { \varphi ^ { \star } } ^ { \pi } } [ Q ] = Q )$ . What does P -learning converge to? Unlike Q-learning [23], P -learning solves a supervised learning problem using a stationary objective $\mathcal { L } ( \varphi )$ , inheriting the standard convergence guarantees of SGD algorithms.<sup>1</sup> But what does the solution look like? Fixing the policy π and omitting the superscript for brevity, let us first rewrite the goal-conditioned Bellman operator as

$$
\mathcal {T} _ {P _ {\varphi}} (Q) (s, a, g) = \mathbb {E} _ {s ^ {\prime} \sim P _ {\varphi} (s, a)} \left[ M (s ^ {\prime}, g) \right], \quad \text { where } \quad M (s ^ {\prime}, g) := r (s ^ {\prime}, g) + \gamma V (s ^ {\prime}, g)\tag{1}
$$

When $s , A , \mathcal { G }$ are finite, we can assemble a matrix $M \in \mathbb { R } ^ { | \mathcal { G } | \times | \boldsymbol { S } | }$ with entries $M _ { l k } = M ( s _ { k } ^ { \prime } , g _ { l } )$ , and the Bellman equation becomes a linear system, viewing $Q ( s , a ) \in \mathbb { R } ^ { | \mathcal { G } | } , P _ { \varphi } ( s , a ) \in \mathbb { R } ^ { | S | }$ as vectors:

$$
Q (s, a, g _ {l}) = \mathcal {T} _ {\varphi} (Q) (s, a, g _ {l}) = \sum_ {k} P _ {\varphi} (s, a, s _ {k} ^ {\prime}) M _ {l k} \quad \Longrightarrow \quad M P _ {\varphi} (s, a) = Q (s, a)\tag{2}
$$

for each $s , a .$ . Writing $J _ { \varphi } ( s , a )$ for the Jacobian of $P _ { \varphi } ( s , a )$ with respect to φ, P -learning by gradient descent takes the explicit form $\begin{array} { r } { \varphi _ { n + 1 } = \varphi _ { n } - \alpha _ { n } \sum _ { s , a } J _ { \varphi } ( s , a ) ^ { \top } M ^ { \top } ( M P _ { \varphi } ( s , a ) - Q ( s , a ) ) } \end{array}$ . In the tabular setting where $s , A , \mathcal { G }$ are finite and $P _ { \varphi } ( s , a ) = \varphi ( s , a )$ ) with $\varphi : \mathcal { S } \times \mathcal { A }  \mathbb { R } ^ { | \mathcal { S } | }$ , each Jacobian is the identity $J _ { \varphi } ( s , a ) = I$ and the update decouples, using a constant step size $\alpha ,$ as

Tabular P-learning:

$$
P _ {n + 1} (s, a) = P _ {n} (s, a) - \alpha M ^ {\top} \left(M P _ {n} (s, a) - Q (s, a)\right).\tag{3}
$$

Theorem 1 reveals key conditions for P -learning to converge to the true world model. The term $( I - M ^ { + } M ) P _ { 0 }$ represents the underdetermination from value equivalence: when M is rank-deficient $( M ^ { + } M \neq I )$ , multiple WMs yield identical Q-values, and P -learning selects among them based on the initial guess $P _ { 0 } . ^ { ^ { \circ } 2 }$ When M has full rank, the iteration converges to a unique solution $M ^ { + } Q$ in which case $M ^ { + }$ can be viewed as an inverse Bellman map, noting that $M ^ { \hat { + } } = M ^ { - 1 }$ when M is square. In this regime, P -learning can informally be viewed as a way to uniquely extract the agent’s ‘beliefs’ about the world (implicit model $\dot { P ) }$ by sampling its ‘beliefs’ about the value of states and actions (learnt function $Q )$ . If $Q \cdot$ -values are moreover exact, i.e. satisfy ${ \mathcal { T } } _ { P } ( Q ) = Q$ then P -learning converges to the true kernel $P .$ We provide intuition for how goals break value equivalence in Appendix B.1, and formal guarantees in Section 4.

Deterministic MDPs. If dynamics are deterministic, we can parameterise the model as a successor function $P _ { \varphi } : \mathcal { S } \times \mathcal { A }  \mathcal { \bar { S } }$ . The drawback is that backpropagation flows through $\displaystyle r ( P _ { \varphi } ( s , a ) , g )$ and $Q ( P _ { \varphi } ( s , a ) , a ^ { \prime } , g )$ via the chain rule, requiring these to be differentiable almost everywhere. This is usually satisfied when the Q-function is a neural network and r is distance-based (including $r _ { g } ( s ) = \mathbf { 1 } [ | | s - g | | < \sigma ] ) ;$ ; otherwise, methods like evolutionary strategies [25, 26] are appropriate. If S is finite, P -learning can instead be performed via column-matching (Section 4.1). The WM is then unique provided column-injectivity, a much weaker requirement than full-rankness.

## 4 Theoretical Results

Our core theoretical results are sufficient conditions on the goals and reward functions $( \mathcal { G } , r )$ that resolve the value equivalence problem via Q-values, meaning that a unique world model can be extracted from $( Q , \pi , r )$ . When Q-values are exact, we prove that the model coincides with the true transition kernel P . When Q-values are approximate, we provide bounds on the accuracy of the extracted world model, with further results for arbitrary Q-values in Appendix C.6.

For finite MDPs, our results characterise the number of goals |G| needed to identify P uniquely, for various families of reward functions r. For MDPs with continuous $S \subseteq \mathbb { R } ^ { d }$ , uniqueness is typically driven not by count, but coverage of S (excluding Theorems 8 and $9 )$ . In this regime, our results therefore provide guarantees for goals sampled from a distribution with sufficiently broad support, e.g. uniform over a bounded goal region, as is common in GCRL benchmarks like JaxGCRL [27]. ## 4.1 Finite Space

Using our formulation of the Bellman equation (1) as $\mathbb { E } _ { s ^ { \prime } \sim P ( s , a ) } [ M ( s ^ { \prime } , g ) ] = Q ( s , a , g )$ , we show that unique recovery of $P$ is guaranteed by different structural conditions on $M$ depending on kernel stochasticity, but not on the choice of parameterisation for Q-values or policies.

Deterministic MDPs. For deterministic kernels $P : { \mathcal { S } } \times { \mathcal { A } }  { \mathcal { S } } .$ , the Bellman equation (1) collapses to ${ \cal M } ( P ( s , a ) , g ) = Q ( s , a , g )$ . Writing $M ( s ^ { \prime } ) = M ( s ^ { \prime } , \cdot )$ and $Q ( s , a ) = Q ( s , a , \cdot )$ , extracting P reduces to identifying which column of M matches $Q ( s , a )$ via column-matching, i.e.

$$
P (s, a) := \underset {s ^ {\prime}} {\arg \min} \| M (s ^ {\prime}) - Q (s, a) \| _ {1}.
$$

In particular, the arg min (and therefore the kernel P ) is unique provided M is column-injective: $\bar { M ( s ) } \neq M ( s ^ { \prime } )$ for all $s \neq s ^ { \prime }$ . To quantify injectivity, we define the column separation of M as $\begin{array} { r } { \Delta ( \dot { M } ) : = \operatorname* { m i n } _ { s \neq s ^ { \prime } } \| M ( s ) - M ( s ^ { \prime } ) \| _ { 1 } } \end{array}$ . Theorem 2 shows that even with a single goal, (a) $P$ is uniquely determined by exact Q-values $Q ^ { \pi }$ for generic (“almost all”) reward functions and (b) $P$ can also be recovered exactly from ϵ-approximate Q-values if ϵ is sufficiently small.

While Theorem 3(a) is analogous to Theorem 2(a), showing that identifiability holds for generic reward functions when $| \mathcal { G } | \geq | \mathcal { S } |$ , part (b) shows that spanning goals are also sufficient if we shift genericity to policies or discount factors. We provide a stronger version of this result in Appendix C.3 (Proposition 5), including a finite failure set over γ and a treatment of optimal and entropy-regularised policies (functions of $Q )$ . Results for perturbed and Gaussian rewards are provided in Appendix C.4.

In some settings, such as single-goal contrastive RL [28], the actor learns a single unconditional policy $\pi _ { g } = \pi _ { g ^ { \prime } }$ for all $g , g ^ { \prime }$ , trained to maximise an environment-provided goal, but with a critic that encodes Q-values $Q _ { g } ^ { \pi }$ for this policy with respect to all indicator goals $g \in S$ . In this unconditional regime, Theorem 3(b) strengthens to $M ^ { \pi }$ always being full-rank (unlike general policies, cf. Appendix C.5). If we also assume indicator goals, the upper bound improves to $\| \ b { \hat { P } } _ { i j } - \dot { P } _ { i j } \| _ { 1 } \leq 4 \epsilon / ( 1 ^ { \frac { s } { 2 } } - 2 \epsilon )$ for all $\epsilon < 1 / 2$ (Proposition 6), and $M ^ { \pi }$ reduces to the occupancy measure [29].

What about arbitrary $Q \cdot$ -values? While our results are stated for exact or approximate $Q \approx Q ^ { \pi }$ , note that a unique compatible world model can also be extracted for arbitrary Q-functions, e.g. during training, under similar conditions; see Propositions 9 and 10 in Appendix C.6.

Are multiple goals necessary? Could value equivalence instead be broken by Q-values for a single goal, but multiple horizons (discount factors γ) or behaviours (policies π), e.g. Multi-Rainbow [30] or Horde [31]? We prove in Appendix C.7 that this is not generally possible: for any $| S | \geq 4 .$ , there is a family of MDPs in which $P$ cannot be identified from the Q-values $\{ Q _ { r , \gamma } ^ { \pi } \ | \ \pi \stackrel { \cdot } { \in } \Pi , \gamma \in [ 0 , 1 ) \}$ over all policies π and all discount factors γ, for any single-goal reward function $r : { \mathcal { S } }  \mathbb { R } .$

Local MDPs. Sitting between deterministic and fully-stochastic settings, we say that an MDP is N-local if supp $( s , a ) : = | \{ s ^ { \prime } : P ( s ^ { \prime } \mid s , a ) > 0 \} | \le \dot { N }$ for every $( s , a )$ , e.g. a robot who can only move to a neighbourhood of its position in a single timestep. In Appendix C.8 we prove that P can be identified uniquely in local MDPs for $( \mathbf { a } ) \mathbf { \alpha } | \mathcal { G } | \geq N - 1$ generic goals when the support is known, and (b) $| \mathcal { G } | \geq 2 \dot { N } - \mathbf { \bar { 1 } }$ otherwise. This generalises the stochastic case (where the support $N = | S |$ is trivially known) and the deterministic case (where $N = 1$ but the successor state is unknown).

## 4.2 Continuous Space

For continuous $S \subseteq \mathbb { R } ^ { d }$ , the matrix M is replaced by a possibly infinite family $\{ m _ { q } ^ { \pi } \} _ { g \in \mathcal { G } }$ , and invertibility or column-injectivity generalises to whether this family is measure determining or point separating for stochastic or deterministic MDPs; see Appendix D.2. We prove results for two classes of goals $\breve { \mathcal { G } } \subseteq \mathbb { R } ^ { d }$ : (sparse) indicator goals given by $r _ { g } ( \bar { s } ) = \mathbf { 1 } [ | s - g | | < \sigma ]$ with a threshold $\sigma > 0$ , commonly used in GCRL, and Gaussian goals $r _ { g } ( s ) = \exp ( - | | s - g | | ^ { 2 } / 2 \sigma ^ { 2 } )$ with a variance $\sigma > 0$ controlling reward sparsity, which admit stronger guarantees. Theorem 4, stated below, is our most relevant result for MuJoCo environments like Reacher, which often use indicator goals and termination upon arrival, i.e. a termination criterion $D _ { g } ( s ) = \mathbf { 1 } [ | | s - g | | \geq \sigma ]$ that prevents further accumulation of reward once the goal is reached; see formal definition in Appendix D.1.

Theorem 4. Fix any continuous deterministic MDP, policy π, threshold $\sigma > 0$ and a goal set $\mathcal { G } \supseteq \mathcal { S } + B _ { \sigma } ( 0 )$ with indicator rewards $r _ { g } ( s ^ { \prime } ) = \mathbf { 1 } [ \| s ^ { \prime } - g \| < \sigma ]$ and termination upon arrival. Then $\{ m _ { g } ^ { \pi } : g \in \mathcal { G } \}$ is point separating on $s ,$ hence ∃! $P ( Q ^ { \bar { \pi } } )$

Our full set of results, including those for stochastic kernels, are stated and proven in Appendix D. In the deterministic setting, we show that a sufficiently large but finite number of terminating Gaussian goals is sufficient to identify $P$ (Theorem 8), while only 2d + 1 non-terminating Gaussian goals are enough when $V ^ { \pi }$ is real-analytic (Theorem 9). For stochastic kernels, Theorems 6 and 7 show that a goal set with non-empty interior suffices for Gaussian goals, and $\mathcal { G } \supseteq \mathcal { S } + B _ { \sigma } ( 0 )$ for indicator goals, but only for unconditional policies. The challenging intersection of stochastic kernels and general (goal-conditioned) policies is beyond the scope of this paper.

## 5.1 Reacher

Our theoretical guarantees for continuous $S \subseteq \mathbb { R } ^ { d }$ require an infinite number of indicator goals covering all dimensions of S. However, we find that accurate world model extraction in Reacher is feasible even with a small number $| \mathcal { G } | = 4$ of goals defined only with respect to fingertip position $( x , y ) = ( \cos \theta _ { 1 } + \cos \theta _ { 2 } , \sin \theta _ { 1 } + \sin \theta _ { 2 } )$ . We consider the goals with unit distance in the cardinal directions, $\mathcal { G } = \{ ( \pm 1 , 0 ) , ( 0 , \pm 1 ) \}$ , covering a limited portion of the fingertip space $[ - 2 , 2 ]$ . The indicator (sparse) reward function is $r _ { g } ( \theta , \omega , x ) = \mathbf { 1 } \{ \| x - g \| < \sigma \}$ , with $\sigma = 0 . 2$ matching ReacherHard in MuJoCo Playground [36], and episodes terminate upon reaching the goal region.

Despite imperfect $Q \mathrm { - v a l u e s }$ (normalised mean squared error $\mathtt { N M S E } = 5 . \dot { 7 } \times 1 0 ^ { - 1 } )$ , the WM matches ground truth with extremely high fidelity $( \mathtt { N M S E } = \bar { 1 } . 2 \times 1 0 ^ { - 4 } )$ To further validate accuracy, and determine whether P -learning reveals hidden generalisation capabilities, we train policies exclusively inside the extracted WM using value iteration, for three unseen goals that are increasingly far from the training distribution: (i) far fingertip: reach fingertip position<sub>√ √</sub> $( x , y ) \ = \ ( { \sqrt { 2 } } , { \sqrt { 2 } } )$ , which is twice as far as any training goal; (ii) target angle: reach joint configuration $\theta = ( 0 , \pi )$ , noting that distinct angle config urations can induce identical positions; and (iii) target velocity: reach velocity $\omega = ( 2 , 2 )$ , where ω covers a different dimension as the training goals. ## 5.2 MountainCar

In MountainCar, the environment goal is to reach position $x = 0 . 5$ under 200 timesteps. Unlike Reacher, which has goal-conditioning baked in, we augment the environment to support arbitrary goals. We train a MountainCar agent using 4 linearly spaced, position-based goals, with a sparse reward function $r _ { g } ( x , v ) = \mathbf { 1 } \{ | x - g | < \sigma \}$ , where $g \in [ - 1 . 2 , 0 . 6 ]$ ], with termination upon arrival and threshold $\sigma = 0 . 1$ . The original environment goal corresponds exactly to $g = 0 . 6$ . Again, the dynamics extracted from a trained PQN agent match the true transition kernel with high fidelity $( \mathrm { { N M S E } } = 6 . 7 \times 1 0 ^ { - 3 } )$ To further validate accuracy, we consider three out-of-distribution goals: (i) Fast car: reach velocity $v = 0 . 0 6 ;$ (ii) Gentle car: reach the top of the hill $x = 0 . 6$ without exceeding $| \boldsymbol { v } | = 0 . 0 5$ (the unconstrained optimal policy uses $\lvert v \rvert \geq 0 . 0 6 )$ ; (iii) Shortest path: find the shortest path to one of two goals $x = - 1 . 0$ and $x = 0 . 4 ,$ which, as noted by Touati and Ollivier [10], could not be achieved using successor features based on the indicator-goal family.

## 6 Related Work

Value equivalence. Grimm et al. [6] introduced the value equivalence (VE) principle, and showed that the equivalence class collapses to a single point for value functions that form a basis of $\mathbb { R } ^ { | \boldsymbol { S } | }$ combined with $\lvert A \rvert$ pointwise-linearly-independent policies, neither of which we assume. Their work focuses on learning a surrogate model to enhance planning using environment samples, while ours addresses the problem of extracting an agent’s internal world model with access only to $( Q , \pi , r )$ . Algorithms such as MuZero [38], VAML [39, 4] and unified frameworks [40] also learn value-equivalent models without addressing identifiability. Fellows et al. [41] demonstrate that Bayesian model-free methods can learn Bayes-optimal policies, implying that model-free approaches implicitly encode a posterior over environment dynamics, and hence a space of world models. Relatedly, delayed $Q \cdot$ -learning [42] achieves PAC sample complexity comparable to model-based RL despite never representing $\check { P }$ explicitly. Conversely, Zhu et al. [43] exhibit MDP families where $P$ admits exponentially smaller circuit representations than $Q ^ { \star }$ , which motivates extracting P as a compact summary of an agent.

GCRL. GCRL has emerged as a popular field wherein agents are trained on a number of tasks [44, 35, 29], with the bulk of recent research focused on enhancing the performance of goal-conditioned agents, e.g. by scaling compute usage [45], goal set [46] or network size [37]. Our work takes a different tack by analysing what agents encode during and after training, and showing that their implicit representation of the world improves with the number of goals, network size and performance.

World models from agents. Richens et al. [47] proved that ϵ-optimal policies for sufficiently diverse multi-step goals of depth d recover approximate dynamics, but require competence on $d n ^ { 2 } m$ goals; they do not address the more realistic setting of single-step goals, nor continuous MDPs. Adamczyk [48] showed that converged $Q \cdot$ -values encode dynamics under a “reverse Lipschit $\boldsymbol { z } ^ { \flat }$ assumption on ${ \bar { V } } ^ { \pi }$ which rarely holds in practice, and is limited to deterministic MDPs and a single goal. Turner [49, Theorem F.117] proved that $V ^ { \star }$ recovers deterministic MDPs up to isomorphism, but not in stochastic environments. Bush et al. [50] provide mechanistic-interpretability evidence that model-free agents develop implicit forward models, but do not address uniqueness or extraction.

Decoupling dynamics from reward. The successor representation [51] and successor features [8, 9] decompose value functions into transition- and reward-dependent components, but only address families of reward functions that can be decomposed as linear functions of shared features. This excludes e.g. the indicator functions in continuous environments [32], which would require infinitely many features to represent. Forward-backward learning [10] relaxes this constraint significantly, and the successor measure of Lehnert and Littman [52, p. 7] and Blier et al. [29, Prop. 1] was shown to be invertible in the special case of unconditional π, indicator goals and exact Q, but does not address identifiability or extraction. Reward-free RL [53] and inverse RL [54] solve orthogonal problems to ours: reward-free exploration produces a dataset sufficient to plan for any downstream reward, whereas we show the dual phenomenon: diverse reward-rich training implicitly encodes P . Inverse RL recovers r from $( P , { \bar { \pi } } )$ ), while we recover P from $( r , \pi , Q )$ . Indeed, RL, Q-learning, and P-learning can all be thought of as different resolutions to the same inconsistency (the Bellman residual) between a world model P , action-values Q, and rewards r – an instance of a general pattern that also has analogues in decision theory and supervised learning [55].

## 7 Conclusion

In this work, we provided sufficient conditions under which it is possible to recover environment dynamics from the Q-values of a goal-conditioned model-free agent, for a variety of MDP classes (deterministic or stochastic, discrete or continuous). We introduced a novel method, P -learning, which enables the extraction of this implicit world model. We subsequently showed, empirically, the accuracy and effectiveness of P -learning in a number of RL environments, despite goal sets that significantly breach our theoretical guarantees. We demonstrated that this WM leads to implicit generalisation capabilities hidden in the agent’s value functions, with zero-shot transfer to reward functions defined on orthogonal variables. Finally, we provided evidence for a relationship between the performance of an agent, and the fidelity of its underlying world model.

Limitations. Our results come with a number of caveats. First, our theoretical results for stochastic MDPs with continuous state spaces only apply to unconditional policies, and while we expect them to generalise, we leave them as open conjectures for future work. Secondly, our work does not encompass partially observable MDPs, or model-free agents that do not learn Q-values. Third, we have not run experiments to test whether P -learning scales to very large, finite environments. Finally, P -learning is not a substitute for model-based RL; instead, we focus on the conceptual and empirical connection between model-based, model-free and goal-conditioned RL.

Future Work. We hope our results will inspire a deeper understanding of the implicit generalisation capabilities lurking in model-free agents; hybrid methods that leverage them; and interpretability or auditing tools based on internal world models, to ensure that agents can efficiently be repurposed when they are trained using reward functions that are, perhaps inevitably, misspecified.

## A.1 Derivation of P -Learning

We provide pseudocode for P -learning in Algorithm 1 below, with batch size 1 for simplicity. To derive the update, recall the definition of the Bellman residual

$$
\mathcal {L} (\varphi) := \| \mathcal {T} _ {\varphi} ^ {\pi} (Q) - Q \| _ {d} ^ {2} = \frac {1}{2} \mathbb {E} _ {(g, s, a) \sim d} \left[ \left(\mathcal {T} _ {\varphi} ^ {\pi} (Q) (s, a, g) - Q (s, a, g)\right) ^ {2} \right] = \frac {1}{2} \mathbb {E} _ {d} [ \delta_ {\varphi} ^ {2} ],
$$

where $\delta _ { \varphi } ( s , a , g ) = { \mathcal { T } } _ { \varphi } ^ { \pi } ( Q ) ( s , a , g ) - Q ( s , a , g )$ is the TD error. By the chain rule, and since the expectation does not depend on $\varphi ,$ we have

$$
\nabla_ {\varphi} \mathcal {L} (\varphi) = \mathbb {E} _ {(g, s, a) \sim d} \left[ \delta_ {\varphi} (s, a, g) \nabla_ {\varphi} \mathcal {T} _ {\varphi} ^ {\pi} (Q) (s, a, g) \right].
$$

We now assume three standard regularity conditions for the score-function gradient estimator [56], namely: $( \mathrm { i } ) \ P _ { \varphi }$ is continuously differentiable in $\varphi , ( \mathrm { i i } ) ~ P _ { \varphi }$ has full support, and (iii) there is an integrable function $g : { \mathcal { S } } $ <sup>R</sup> with $\begin{array} { r } { \operatorname* { s u p } _ { \varphi } \| \nabla _ { \varphi } \dot { P _ { \varphi } } ( s ^ { \prime } \mid s , \dot { a } ) \| _ { 1 } \le g ( s ^ { \prime } ) } \end{array}$ for all $s , a , s ^ { \prime }$ . Then the gradient can be estimated via the log-derivative trick [56]:

$$
\begin{array}{r l} & {\nabla_ {\varphi} \mathcal {L} (\varphi) = \mathbb {E} _ {(g, s, a) \sim d} \left[ \delta_ {\varphi} (s, a, g) \nabla_ {\varphi} \mathbb {E} _ {s ^ {\prime} \sim P _ {\varphi} (s, a), a ^ {\prime} \sim \pi (\cdot | s ^ {\prime}, g)} \left[ r (s ^ {\prime}, g) + \gamma Q (s ^ {\prime}, a ^ {\prime}, g) \right] \right]} \\ & {\qquad = \mathbb {E} _ {(g, s, a) \sim d, s ^ {\prime} \sim P _ {\varphi} (s, a), a ^ {\prime} \sim \pi (s ^ {\prime}, g)} \left[ \delta_ {\varphi} (s, a, g) (r (s ^ {\prime}, g) + \gamma Q (s ^ {\prime}, a ^ {\prime}, g)) \nabla_ {\varphi} \log P _ {\varphi} (s ^ {\prime} \mid s, a) \right]} \end{array}
$$

To reduce variance and make the per-sample direction of this update explicit, we subtract the baseline $Q ( s , a , g )$ to get a per-sample TD error

$$
\hat {\delta} _ {\varphi} (s, a, g, s ^ {\prime}, a ^ {\prime}) := r (s ^ {\prime}, g) + \gamma Q (s ^ {\prime}, a ^ {\prime}, g) - Q (s, a, g),
$$

and the update, as claimed in the main text, simplifies to

$$
\nabla_ {\varphi} \mathcal {L} (\varphi) = \mathbb {E} _ {(g, s, a) \sim d, s ^ {\prime} \sim P _ {\varphi} (s, a), a ^ {\prime} \sim \pi (s ^ {\prime}, g)} \big [ \delta_ {\varphi} (s, a, g) \hat {\delta} _ {\varphi} (s, a, g, s ^ {\prime}, a ^ {\prime}) \nabla_ {\varphi} \log P _ {\varphi} (s ^ {\prime} \mid s, a) \big ]\tag{4}
$$

Note that the baseline preserves unbiasedness: $Q ( s , a , g )$ is constant under the inner sampling of $( s ^ { \prime } , a ^ { \prime } )$ , so it factors out and multiplies the expected score $\dot { \mathbb { E } } _ { s ^ { \prime } \sim P _ { \varphi } ( s , a ) } [ \nabla _ { \varphi }$ log $P _ { \varphi } ( s ^ { \prime } \mid s , a ) ]$ , which is zero because $\begin{array} { r } { \int _ { \mathcal { S } } P _ { \varphi } ( s ^ { \prime } \mid s , a ) d s ^ { \prime } = 1 } \end{array}$ . Now the TD error $\delta _ { \varphi } ( s , a , g )$ does not depend on the variables $( s ^ { \prime } , a ^ { \prime } )$ in the outer expectation, so we can factor it out, yielding:

$$
\nabla_ {\varphi} \mathcal {L} (\varphi) = \mathbb {E} _ {(g, s, a) \sim d} \left[ \delta_ {\varphi} (s, a, g) \mathbb {E} _ {s ^ {\prime} \sim P _ {\varphi} (s, a), a ^ {\prime} \sim \pi (s ^ {\prime}, g)} \left[ \hat {\delta} _ {\varphi} \nabla_ {\varphi} \log P _ {\varphi} (s ^ {\prime} \mid s, a) \right] \right].

$$

## B Value Equivalence and Pseudo-World Models

## B.1 Intuition: Breaking Value Equivalence

We provide intuition for how exactly spanning goals break value equivalence using the notion of “test functions” to determine unknown distributions. Recalling the Bellman operator

$$
\mathcal {T} _ {P} (Q) (s, a, g) = \mathbb {E} _ {s ^ {\prime} \sim P (s, a)} \left[ M _ {g} (s ^ {\prime}) \right], \quad \text { where } \quad M _ {g} (s ^ {\prime}) := r _ {g} (s ^ {\prime}) + \gamma V _ {g} (s ^ {\prime}),
$$

notice that the Bellman equation reduces to $Q ( s , a , g ) = \mathbb { E } _ { s ^ { \prime } \sim P ( s , a ) } \left[ M _ { g } ( s ^ { \prime } ) \right]$ , which can be viewed as imposing |G| constraints on the expectations of known “test functions” or “Bellman probes ${ \ " } M _ { g }$ under the unknown distribution $\bar { P ( s , a ) }$ . If the agent is trained on a single goal $^ { g , }$ it is natural to expect that there will be many world models $\hat { P }$ that have the same expectation under the single test function, i.e. such that $\mathbb { E } _ { s ^ { \prime } \sim \hat { P } ( s , a ) } \left[ M _ { g } ( s ^ { \prime } ) \right] = Q ( s , a , g )$ , inducing value equivalence.

However, probability distributions can be determined by expectations over multiple test functions: beginning with the finite setting, a distribution $p \in \Delta ^ { n }$ is uniquely determined by the first $n - 1$ moments of any injective random variable (‘test function’) $\dot { X ^ { \mathrm { ~ } } } : \dot { \lceil n \rceil }  \mathbb { R }$ . For example, in the 1-dimensional case $p = \left( p _ { 1 } , 1 - p _ { 1 } \right)$ , if we know the first moment $\mathbb { E } \big [ \dot { X } \big ] = p _ { 1 } X ( 1 ) + ( 1 - p _ { 1 } ) X ( 2 )$ we can invert the system to determine $p _ { 1 } = ( \mathbb { E } [ X ] - X ( 2 ) ) / ( X ( 1 ) - X ( 2 ) )$ ) uniquely. For general $p \in \Delta ^ { n }$ , the first n moments induce a linear system of equations known as a Vandermonde system, which is invertible if and only if X is injective – meaning that p can be recovered uniquely.

However, the Bellman probes are not simple functions like monomials, and it is not clear that they will similarly induce an invertible system. For continuous MDPs Section 4.2, the picture is even more involved, and invertibility generalises to a set of test functions being measure determining, meaning that distinct Borel measures have distinct expectations.

## B.2 World Models and Pseudo-World Models

We introduce two spaces of stochastic world models:

$$
\mathcal {P} := \{P: \mathcal {S} \times \mathcal {A} \rightarrow \Sigma (\mathcal {S}) \} \quad \text { and } \quad \mathcal {P} _ {\Delta} := \{P: \mathcal {S} \times \mathcal {A} \rightarrow \Delta (\mathcal {S}) \} \subset \mathcal {P},
$$

where $\Sigma ( S )$ denotes the space of finite signed measures over ${ \mathcal { S } } .$ . Elements of ${ \mathcal { P } } _ { \Delta }$ are valid world models, while elements of $\bar { \mathcal { P } } \backslash \mathcal { P } _ { \Delta }$ are pseudo-world models: signed measures that may still satisfy the Bellman equation $\mathcal { T } _ { P } ( Q ) = \dot { Q }$ but do not correspond to valid probabilistic dynamics. In particular, the P -learning iteration $P _ { t + 1 } ( s , a ) = P _ { t } ( s , a ) - \alpha M ^ { \top } ( M P _ { t } ( s , a ) - Q ( s , a ) )$ does not preserve positivity or normalisation, so the limit $P _ { \infty } = M ^ { + } Q + ( \dot { I } - \dot { M ^ { + } M ^ { } } ) P _ { 0 }$ generally lies in $\bar { \mathcal { P } }$

However, if the conditions of Theorem 3(a) are satisfied, then there exists a true kernel $P \in { \mathcal { P } } _ { \Delta }$ with $Q = M P$ , and M has full rank, so $P _ { \infty } = M ^ { + } M P = P \in \mathcal { P } _ { \Delta }$ , so the iteration converges to a true world model. Moreover, in realistic settings with function approximation, the world model is typically parameterised as a neural network $P _ { \varphi } : \mathcal { S } \times \mathcal { A }  \mathcal { P }$ with a softmax output layer, so P -learning is constrained to the simplex by construction. Finally, in deterministic MDPs, a world model is defined as a function $P : \mathcal { S } \times \mathbf { \bar { \mathcal { A } } }  \mathcal { S }$ , so the distinction collapses, and either column-matching or approximate methods always return a valid world model. If none of these conditions hold, the pseudo-world caveat can be mitigated in full generality by a projected variant of P -learning, given by

$$
P _ {t + 1} (s, a) = \Pi_ {\Delta} \left(P _ {t} (s, a) - \alpha M ^ {\top} \left(M P _ {t} (s, a) - Q (s, a)\right)\right),
$$

where $\Pi _ { \Delta }$ is the Euclidean projection onto the simplex. Since projection onto a closed convex set is non-expansive, the iteration still converges, and the limit is $\begin{array} { r } { \dot { P } _ { \infty } ^ { \tilde { \Delta } } = \arg \operatorname* { m i n } _ { P \in \mathcal { P } _ { \Lambda } } \| M P - Q \| ^ { 2 } } \end{array}$ This is not generally equal to post-hoc projection $\Pi _ { \Delta } ( P _ { \infty } )$ of the unconstrained limit, which ignores the geometry of the loss landscape and can return a strictly worse fit than $P _ { \infty } ^ { \Delta }$ when M is poorly conditioned. In the approximate setting of Theorem 3(b), where M is full-rank, both post-hoc projection and projected P -learning inherit the same asymptotic upper bound.

Definition 4 (Measure-determining family). A set $\mathcal { F }$ of bounded measurable functions $f : S  \mathbb { R }$ is measure determining if for any probability measures $\mu , \nu \in \Delta ( S )$

## E Reacher and MountainCar Experiments

In this section we provide additional details for the continuous-control experiments of Section 5. We train goal-conditioned Q-functions with PQN [20] and HER [35], then fit a world model $P _ { \varphi }$ to the converged Q-values via P -learning (Section 3). Throughout, the WM is parameterised as a residual MLP $\bar { P } _ { \varphi } ( s , a ) = s + h _ { \varphi } ( s , a )$ , trained with $\ell _ { 1 }$ Bellman residual loss function on independently sampled $( s , a , g )$ batches. To train policies on unseen goals using the WM, we run value iteration on $\hat { P }$ over a discretised grid (resolution 50 for Reacher, 200 for MountainCar) to obtain a WM-derived policy.

We complement the continuous-control experiments with a finite-state-space study in FourRooms [34], a $\bar { 1 1 } \times 1 1$ gridworld divided into $4 \times 4$ rooms by interior walls and connected by single-cell corridors. After removing wall cells, the open state space has $\lvert S \rvert = 6 8$ cells, the action space is $\mathcal { A } = \{ \mathrm { u p } , \mathrm { r i g h t } , \mathrm { d o w n } , \mathrm { l e f t } \}$ with $| { \mathcal { A } } | = 4 .$ , and the episode horizon is $T _ { \mathrm { m a x } } = 2 0 0$ To cover the regimes of our finite-MDP theory (deterministic in Theorem $2 ;$ local in Theorem 5; stochastic in Theorem 3), we instantiate three variants of increasing stochasticity. Across all three, the WM-derived policy reaches near-optimal return on unseen goals from a small fraction of the $\lvert S \rvert = 6 8$ candidate training goals: 1 goal for deterministic, 4 for windy, and roughly 20 for teleporting – consistent with our identifiability theory in the first two cases, and exceeding our expectations in the third. To summarise the environments and results:

1. Deterministic (Figures 8 and 9). Each action moves the agent one cell in the chosen cardinal direction; walls keep the agent in place. A single training goal $( | { \mathcal { G } } | = 1 )$ already drives $\hat { P }$ to zero world-model MSE within 8M env steps and the WM-derived policy is exactly optimal on both unseen goals, in line with Theorem 2.

2. Windy (Figures 8 and 10). The chosen action is realised $\mathbf { w . p . } \ \frac { 1 } { 2 }$ , perturbed $9 0 ^ { \circ }$ counterclockwise or clockwise each $\mathbf { w . p . \ } { \scriptstyle { \frac { 1 } { 4 } } } .$ . Here, $| \mathcal { G } | = 4$ training goals already drive the WMderived policy to within $\sim 1 \%$ of optimal return on both unseen goals.

3. Teleporting (Figures 8 and 11). Four cells $( 4 , 4 ) , ( 4 , 6 ) , ( 6 , 4 ) , ( 6 , 6 )$ teleport the agent uniformly into the 16 cells of the diagonally opposite $4 \times 4$ room. Here, $\left| \mathcal { G } \right| ^ { - } = 2 0$ training goals – well short of the $\lvert \mathcal { G } \rvert = \lvert S \rvert = 6 8$ worst case of Theorem 3 – already drive the WM-derived policy to within $\sim 0 . 1 \%$ of optimal return on both unseen goals.

For each variant, the training goals are the first |G| cells of a fixed seeded permutation of the 68 states, so that the goal subsets nest as |G| grows; all experiments use 10 seeds.

The reward function differs across variants in line with the regime each one targets: the windy and teleport variants use the indicator reward $r _ { g } ( s ) = \delta _ { g s } ,$ while the deterministic variant uses the noise perturbed form $r _ { g } ( s ) = \delta _ { g s } - \xi _ { g s }$ with each $\xi _ { g s } \sim \mathsf { \breve { U } } [ 0 , 1 ]$ drawn i.i.d. at initialisation, instantiating the noise-injection recipe stated as a corollary of Theorem 2. We take negative perturbation in order to guarantee that the optimal policy still seeks the goal, noting that $r _ { g } ( g ) \ge 0 \ge r _ { g } ( s )$ if $s \neq g$

We extract $\hat { P }$ from the trained PQN agent by P -learning via linear programming (LP), as defined in Appendix F.1, which we found to be fastest and most effective in this finite, one-hot-encoded setting, compared with function approximation. For the deterministic variant we use column matching, which is exact under the genericity condition of Theorem 2. As for MountainCar and Reacher, we evaluate $\hat { P }$ directly via the MSE, and on two unseen goals via value-iteration on $\hat { P } .$ . ## F.1 P -learning via linear programming

Recall from Equation 2 that for finite MDPs, the P -learning fixed-point equation $T _ { P } ^ { \pi } ( Q ) = Q$ decouples per $( s , a )$ into the linear system $M P ( s , a ) = Q ( s , a )$ , with $M \in \mathbb { R } ^ { | \mathcal { G } | \times | \mathcal { S } | } , M _ { l k } =$ $r ( s _ { k } ^ { \prime } , g _ { l } ) + \gamma V ( s _ { k } ^ { \prime } , g _ { l } )$ , and unknown row $P ( s , a ) \in \Delta ^ { | s | }$ . For higher efficiency, we directly solve the $\mathrm { p e r } _ { - } ( s , a )$ ) system with constrained linear programming (LP) via SciPy, instead of using tabular P -learning. The full sweep over $| S | | { \mathcal { A } } | = 2 7 2$ pairs is computed on a single CPU in < 1 second.

Local variant. The windy variant is an N-local MDP as defined in 4; we assume this local prior is known in order to illustrate our result for local MDPs, Theorem 5, namely, that N generic goals are sufficient to recover the world model. We therefore restrict the LP support to the cardinal-4 neighbours of s plus s itself, reducing each per-(s, a) LP from |S| = 68 to 5 unknowns. This is a geometric prior derived from the gridworld topology, which injects no information about the probability masses in the true kernel.

Deterministic variant. For deterministic FourRooms, we use column matching: ${ \hat { P } } ( s , a ) = e _ { k } ,$ ⋆ with $\begin{array} { r } { k ^ { \star } = \arg \operatorname* { m i n } _ { k } \| M _ { \cdot , k } - q \| _ { 1 } } \end{array}$ . This is the LP above with the simplex constraint replaced by a pure argmin; it is exact when M is column-injective (Theorem 2) and requires no LP solver.

In all three cases, the LP solver is a numerical-stability and speed tradeoff over gradient-based P -learning, not a methodological one: both target the same Bellman residual $\| \mathscr { T } _ { P } ^ { \pi } ( \overline { { Q } } ) - Q \| ^ { 2 }$ and inherit the same identifiability guarantees of Appendix C.

## F.4 Teleporting FourRooms

The teleporting variant injects fully-stochastic transitions at four teleport cells $( 4 , 4 ) , ( 4 , \bar { 6 } ) , ( 6 , \bar { 4 } ) , ( 6 , 6 )$ , each of which re-emits the agent uniformly into the 16 cells of the diagonally opposite $4 \times 4$ room; all other transitions are deterministic 4-connected moves. We train PQN on $| \mathcal { G } | \overset { - } { \in } \{ 5 , 1 0 , 2 0 , 6 8 \}$ goals over 10 seeds, and evaluate on one-unsafe (as before) and teleport-unsafe (all four teleport cells “unsafe” giving zero reward and terminating the environment).

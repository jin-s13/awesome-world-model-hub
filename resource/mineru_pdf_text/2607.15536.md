## Abstract

3D Gaussian Splatting (3DGS) captures scenes by coupling explicit geometry (position, covariance) with view-dependent photometry (Spherical Harmonics). However, building SE(3)- equivariant architectures on these primitives presents a fundamental representation bottleneck. Color has been treated as a signal rather than a geometric entity, making it nontrivial to unify symmetry across geometry and appearance as the camera frame changes. While translations are handled by relative coordinates, rotations act heterogeneously across attributes: $\mu \mapsto R \mu .$ $\Sigma \mapsto R \Sigma R ^ { \intercal }$ , and $f _ { \ell } \mapsto D ^ { \ell } ( R ) f _ { \ell }$ . This mismatch complicates strict equivariance, leading existing methods to either discard or flatten SH coeficients, thereby breaking symmetry.

We propose a unified solution rooted in representation theory: for SH degrees $\ell \ \leq \ 2 ,$ photometry is algebraically isomorphic to a rank-2 geometric tensor. We prove that the Wigner D action on these SH coeficients can be exactly reformulated as the conjugation action on $3 \times 3$ matrices. Leveraging this, we introduce the Unified Matrix Embedding, a lifting that maps all Gaussian attributes into a unified carrier space, gl(3).

Building on “Color-as-Geometry” formulation, we present E3DGS, a rigid-body (SE(3)) equivariant architecture that processes 3D Gaussians without Clebsch–Gordan tensor products. Evaluations on object vision and action-conditioned Gaussian world modeling demonstrate that our unified approach yields strong robustness under camera-frame changes and improved data eficiency.

## 1 Introduction

The physical world is not merely a collection of shapes; it is an interplay of geometry and light. 3D Gaussian Splatting (3DGS) [20] explicitly models this duality by assigning Spherical Harmonic (SH) coeficients to each primitive to capture view-dependent appearance. Yet, in the context of deep representation learning, this rich photometric information is often discarded. Current state-of-the-art methods (e.g., [28, 23, 26, 51]) strip away view-dependent SH coeficients in their 3DGS-based learning frameworks to avoid the complexities of rotational symmetries, reducing a glossy, textured scene to a matte, colored point cloud. This architectural compromise inherently limits the model’s capacity to distinguish objects with identical geometries but distinct material properties (e.g., a matte plastic cup versus a shiny metallic mug).

This simplification stems from a fundamental bottleneck in 3D deep learning: strict SE(3) equivariance. While translation equivariance can be elegantly achieved using relative coordinates, rotation poses a severe challenge. Geometric attributes like position (x) and covariance (Σ) admit standard tensor transformation rules under rotation $R \in \mathrm { S O ( 3 ) }$ , whereas SH coeficients transform via Wigner-D matrices. Integrating these disparate data types into a single equivariant pipeline typically requires heavy machinery, such as Tensor Field Networks (TFNs) [43]. For scenes parameterized by millions of Gaussian primitives, relying on Clebsch–Gordan tensor products to process these mixed representations becomes computationally prohibitive [14]. Consequently, existing 3DGS learning frameworks lack a unified equivariant formulation.

To achieve rotation robustness, prior works either rely on extensive data augmentation or bypass the symmetry problem entirely by discarding all view-dependent SH coeficients (degrees $\ell \geq 1 )$ . By reducing appearance solely to the 0-th order SH, they treat photometry as a static scalar signal. This simplification fundamentally fails to model the view-dependent complexities of the real world.

To resolve this representation mismatch, we propose a paradigm shift: treating photometry as geometry. For spherical harmonics of degrees $\ell \leq 2 ,$ the coeficient spaces $\mathbb { R } ^ { 2 \ell + 1 }$ realize the same irreducible representations $( V _ { 0 } \oplus V _ { 1 } \oplus V _ { 2 } )$ that appear in the $3 \times 3$ matrix space gl(3) under conjugation. We construct linear intertwiners $\Phi _ { \ell }$ that map SH coeficients directly into these corresponding matrix subspaces, replacing the Wigner-D action with the simple conjugation rule that governs geometric tensors. By lifting each Gaussian primitive into a stack of $3 \times 3$ matrix channels, all rotation-active attributes—both geometric and photometric—transform via a single, unified operation: $M \mapsto R M R ^ { \top }$ . Fig. 1 summarizes this unification and the resulting applications to object recognition and action-conditioned world modeling.

Building upon this Color-as-Geometry formulation, we introduce E3DGS. To the best of our knowledge, this is the first formulation that makes the view-dependent appearance of 3DGS an equivariant geometric object, allowing geometry and photometry to transform under a single conjugation law. Our core contributions are:

1. Color-as-Geometry. We show that view-dependent photometry is itself an equivariant geometric object: an explicit intertwiner identifies the SH(0–2) coeficients with the conjugation carrier ${ \mathfrak { g l } } ( 3 )$ so that appearance and geometry of a 3D Gaussian transform by the single rule $M \mapsto R M R ^ { \intercal }$

This is, to our knowledge, the first time view-dependent appearance is treated as an equivariant tensor for learning on 3DGS.

2. A complete family of matrix carriers. We prove that every spherical-harmonic degree can be represented exactly as matrix conjugation on a carrier End $( V _ { k } )$ , and we identify which degrees each carrier covers. The $3 \times 3$ matrix used in our model is the smallest such carrier and covers view-dependent appearance up to degree 2; higher degrees are handled by larger carriers in the same family.

3. Adjoint-equivariant transformer for 3DGS. We instantiate a matrix-native rigid-body (SE(3)) equivariant encoder with Ad-equivariant operations (ReLN-Attention, ReLN-LayerNorm) whose pairwise interaction reduces to an SO(3)-invariant scalar contraction with O(1) per-pair cost, avoiding the Clebsch–Gordan tensor products whose cost grows steeply with representation degree.

4. Validation on 3DGS benchmarks. We instantiate the encoder as an Equivariant Gaussian MAE and as an action-conditioned Gaussian world model, and evaluate on object-level recognition and action-conditioned manipulation, demonstrating rotation robustness and label eficiency across camera-frame changes.

## 2 Related Work

## 2.1 3D Gaussian Splatting and the Representation Mismatch

3D Gaussian Splatting (3DGS) parameterizes scenes using anisotropic Gaussians with explicit geometry (means, covariances) and view-dependent photometry (Spherical Harmonics, SH) [20, 29]. Recent feed-forward models predict these primitives directly from sparse observations, establishing 3DGS as a reusable scene representation for downstream perception and decision-making [6, 40, 41]. However, this explicit parameterization introduces a representational mismatch under diferent camera poses or spatial transformations: geometric attributes follow standard SE(3) or SO(3) tensor rules, while SH coeficients transform via Wigner-D matrices [45, 18, 32]. Consequently, direct fusion of these attributes either breaks rotational symmetry or necessitates computationally intensive tensor-product pipelines.

## 2.2 Representation Learning and Downstream Tasks on 3DGS

A growing body of work processes 3DGS primitives as direct inputs for scene understanding. Object-centric and scene-level pipelines, such as ShapeSplat and SceneSplat, enable representation learning and vision–language pretraining directly on Gaussians [28, 23, 27]. Concurrently, 3DGS supports open-vocabulary segmentation, semantic querying, and interactive editing by embedding language-aligned features or optimizing prompt-driven graph cuts [37, 16, 31, 22, 38, 5, 7, 19, 36, 17]. Dynamic 3DGS has also been integrated into language-conditioned robotic manipulation frameworks, such as ManiGaussian [26]. Despite these advances, existing methods typically circumvent the complexity of joint geometric–photometric rotation. They either reduce photometry to viewindependent components (SH0), discard higher-order efects, or rely on heuristic data augmentation to approximate rotational robustness. Our work provides the missing symmetry constraint, enabling joint equivariant learning of geometry and higher-order photometry.

## 2.3 Equivariant Architectures and Matrix-Based Alternatives

Equivariance provides an inductive bias for robustness and data eficiency when task-relevant symmetries are present, and it has become a standard design principle in modern geometric deep learning [4, 8, 47, 46]. In 3D deep learning, standard approaches achieve SE(3) equivariance using irreducible representations and Clebsch–Gordan (CG) tensor products [43, 14, 48, 9, 15]. While highly expressive, the cost of these tensor products scales steeply with the representation degree, creating runtime and memory bottlenecks [42, 3, 50, 24]. To improve scalability, alternative frameworks explore vector-based models, message passing, and Lie-group convolutions [10, 35, 12].

Cartesian-tensor networks. A complementary and closely related line replaces sphericalharmonic/CG machinery with Cartesian tensor features. Most directly related to us, TensorNet [39 represents atomic environments with rank-2 Cartesian tensors and decomposes them into scalar, vector, and symmetric trace-free parts—the same $V _ { 0 } \oplus V _ { 1 } \oplus V _ { 2 }$ irreducible content carried by gl(3) under conjugation—and processes them through matrix products. Our construction difers in what is placed in the carrier : Cartesian-tensor potentials build tensors from geometric (relative-position) features, whereas we identify the view-dependent photometric SH coeficients themselves with the carrier through an explicit intertwiner (“color-as-geometry”), unifying appearance and geometry of a 3D Gaussian in a single conjugation law $M \mapsto R M R ^ { \top }$ . We further show (Theorem 2) that any SH degree is realized by conjugation on a carrier $\operatorname { E n d } ( V _ { k } )$ , so the $3 \times 3$ Cartesian-tensor case is the smallest member of a complete family.

Matrix- and Lie-algebraic equivariant models. Beyond Cartesian tensors, matrix-feature and adjoint-equivariant Lie models process features through matrix operations for improved eficiency, numerical stability, or generality: EMLP [13] solves the equivariant-linear-layer constraints for arbitrary matrix groups, and Lie Neuron / Reductive Lie Neuron (ReLN) constructions [25, 2, 21] target exact GL(n)-equivariance with structured operations on Lie-algebra-valued features. Our backbone reuses ReLN-style Ad-equivariant primitives, but the ReLN framework itself [21] sidesteps photometric rotation by reducing appearance to the view-independent (invariant) SH0 component. In contrast, our contribution is the representation-theoretic identification of higher-order viewdependent photometry, SH(0–2), with the $3 \times 3$ conjugation carrier, and its instantiation for 3DGS; this is a non-trivial step beyond applying an equivariant backbone to scalar colors.

Underlying these constructions is the classical correspondence between low-degree spherical harmonics and low-order tensors—including the symmetric trace-free component that governs Wigner-D rotations and practical real-SH rotation formulas [44, 45, 18, 32]. We make this correspondence explicit and operational by constructing an intertwiner from SH(0–2) into gl(3), so that geometry and photometry are processed uniformly and equivariantly under rigid-body (SE(3)) motions, without CG tensor products in the feature pipeline.

## 3 Unified Geometric–Photometric Equivariance via a Reductive Lie-Algebra Carrier

A 3D Gaussian primitive couples geometry (mean, covariance) with view-dependent photometry (SH). Under a camera-frame change $g = ( R , t ) \in \mathrm { S E } ( 3 )$ , the mean transforms via translation and rotation $( \mu \mapsto R \mu + t )$ , the covariance transforms by congruence $( \Sigma \mapsto R \Sigma R ^ { \top } )$ , and SH coeficients transform degree-wise via Wigner-D matrices $( f _ { \ell } \mapsto D ^ { \ell } ( R ) f _ { \ell } )$ . These heterogeneous SO(3) representations obstruct a single equivariant processing pipeline. In this section, we prove that for SH degrees $\ell \leq 2$ both geometry and photometry admit an exact, unified realization within the reductive Lie algebra gl(3) under matrix conjugation.

$$

$$

$$

Under a spatial rotation $R \in \mathrm { S O ( 3 ) }$ , the covariance transforms by congruence $( \Sigma _ { i } \mapsto R \Sigma _ { i } R ^ { \top } )$ . As the matrix logarithm commutes with orthogonal transformations, the lifted covariance preserves the adjoint equivariance:

## 3.4 ReLN Processing on the Unified Carrier

Given the lifted representations $( H , s )$ of the 3D Gaussian primitives, we construct an encoder $\mathcal { F } _ { \theta }$ utilizing Ad-equivariant Reductive Lie Neurons (ReLN) building blocks [21]. To parameterize nonlinearities without breaking symmetry, we construct Ad-invariant scalars using the non-degenerate modified Killing form on gl(3): $\tilde { B } ( X , Y ) = 6 \mathrm { t r } ( X Y ) - \mathrm { t r } ( X ) \mathrm { t r } ( Y )$ . By stacking equivariant linear and nonlinear layers, the entire block commutes with Ad.

Theorem 3 (Equivariance of the Neural Encoder). Let H and s denote the equivariant features and invariant scalar features of the input 3D Gaussians. An encoder $\mathcal { F } _ { \theta } ( H , s ) = ( H ^ { \prime } , s ^ { \prime } )$ composed of Ad-equivariant ReLN primitives and invariant-weighted aggregations satisfies:

$$
\mathcal {F} _ {\theta} (\mathrm{Ad} _ {R} (H), s) = \left(\mathrm{Ad} _ {R} (H ^ {\prime}), s ^ {\prime}\right) \quad \forall R \in \mathrm{SO} (3),\tag{8}
$$

where $\operatorname { A d } _ { R }$ denotes channel-wise conjugation.

As the scalar features s are SO(3)-invariant, scaling or gating the equivariant channels by these scalars commutes with the adjoint action: $s \cdot \mathrm { A d } _ { R } ( H ) = \mathrm { A d } _ { R } ( s \cdot H )$ . This design guarantees exact global equivariance while leveraging the scalar context.

## 4 Adjoint-Equivariant Architecture for 3D Gaussian Splatting

Building on the unified ${ \mathfrak { g l } } ( 3 )$ carrier (Section 3 and Fig. 1), we introduce E3DGS, an end-to-end equivariant architecture for representation learning on 3DGS. We instantiate E3DGS in two regimes: a Gaussian Masked Autoencoder for large-scale self-supervised pretraining and object recognition (Fig. 2), and an action-conditioned Gaussian world model for robotic manipulation.

E3DGS consists of three stages: (i) a unified lifting that embeds each primitive into a single gl(3) matrix carrier, while collecting rotation-invariant scalars for gating; (ii) an Ad-equivariant ReLN backbone $\mathcal { F } _ { \theta }$ that mixes matrix channels and applies invariant-gated updates; and (iii) task-specific heads with inverse lifting for geometric outputs.

## 4.1 Backbone Instantiation via Ad-Equivariant Operations

We construct the E3DGS backbone by enforcing Ad-equivariance on the gl(3)-valued features, systematically replacing standard Transformer operations that violate rotational symmetry with Lie-algebraic counterparts.

## 4.1.1 ReLN-Attention.

In standard Transformers, attention scores rely on inner products that break under arbitrary rotations if applied directly to geometric coordinates. To resolve this, we propose ReLN-Attention, an equivariant self-attention mechanism native to the gl(3) manifold. We project the tokenized inputs into Ad-equivariant queries, keys, and values $( Q , K , V \in \mathfrak { g l } ( 3 ) )$ . We construct the attention weights $a _ { i j }$ using the modified Killing form $\tilde { B }$ as the invariant similarity measure between query and key matrices:

$$
a _ {i j} = \operatorname{softmax} _ {j} \Bigl (\tilde {B} (Q _ {i}, K _ {j}) \Bigr).\tag{9}
$$

Because the modified Killing form is invariant under conjugation $( \tilde { B } ( \mathrm { A d } _ { R } Q , \mathrm { A d } _ { R } K ) = \tilde { B } ( Q , K ) )$ , the computed scalar weights $a _ { i j }$ are invariant. Consequently, the linear combination $\sum a _ { i j } V _ { j }$ preserves the Ad-equivariance of the value matrices during token mixing.

## 4.1.2 Equivariant Layer Normalization (ReLN-LayerNorm).

To stabilize training without destroying structural symmetry, we generalize VN-LayerNorm [1] from 3D vectors to the ${ \mathfrak { g l } } ( 3 )$ manifold, introducing ReLN-LayerNorm. We compute the scalar magnitude of each $3 \times 3$ channel using the Frobenius norm—a positive-definite invariant metric on gl(3). We apply standard LayerNorm exclusively to these magnitudes and rescale the original matrices:

$$
X _ {c} ^ {\prime} = \frac {\mathrm{LN} \big (\| X _ {c} \| _ {F} \big)}{\| X _ {c} \| _ {F} + \epsilon} X _ {c},\tag{10}
$$

where LN operates over the channel dimension c. $\operatorname { A s } \| \operatorname { A d } _ { R } ( X _ { c } ) \| _ { F } = \| X _ { c } \| _ { F }$ , the scalar multiplication stabilizes variance while preserving geometric orientation.

## 4.1.3 Equivariant Feed-Forward (ReLN-Linear, ReLN-ReLU).

We replace standard feed-forward networks with ReLN-Linear and ReLN-ReLU operations [21] to induce pointwise nonlinearities while maintaining equivariance under the Ad action. Instead of element-wise activations, the network processes matrix channels through Ad-equivariant linear mixings (ReLN-Linear) and invariant-gated activations based on the modified Killing form B<sup>˜</sup> (ReLN-ReLU). Stacking equivariant linear and nonlinear layers preserves exact rotational symmetry.

## 4.2 Task Heads and Inverse Geometric Lifting

The downstream task dictates the symmetry requirements of the prediction head.

Invariant Readout. For invariant tasks $( e . g .$ , classification, global property prediction), we extract scalar invariants from the matrix channels via B<sup>˜</sup>-based self-contractions [21]. These are concatenated with the scalar branch $s _ { i } ,$ pooled, and processed by a standard MLP to yield rotation-invariant predictions.

Equivariant Prediction & Inverse Lifting. For geometric predictions $( e . g .$ , dynamics), the network outputs conjugated matrices $H _ { \mathrm { o u t } } \in { \mathfrak { g l } } ( 3 )$ . To map latent spatial channels back to physical $\mathbb { R } ^ { 3 }$ vectors, we project them onto so(3) and apply the inverse hat map (∨):

$$
\tilde {v} _ {i} = \left(\operatorname{skew} \bigl ((H _ {\mathrm{out}}) _ {\mathrm{pos}} \bigr)\right) ^ {\vee} \in \mathbb {R} ^ {3},\tag{11}
$$

where skew $\begin{array} { r } { \mathbf { \nabla } \cdot ( A ) = \frac { 1 } { 2 } ( A - A ^ { \top } ) } \end{array}$ . Because both the skew projection and the vee map commute with orthogonal transformations, this operation guarantees exact SO(3)-equivariance $( \tilde { v } _ { i } \mapsto R \tilde { v } _ { i } )$ .

## 5 Experiments

We evaluate the E3DGS in two regimes that apply 3D Gaussian primitives: object-level recognition (Section 5.1) and action-conditioned Gaussian world modeling (Section 5.3) for visuomotor control. We adhere to the standard evaluation protocols of the respective benchmarks to ensure controlled comparisons.

Network Implementations and Scalability. We instantiate the E3DGS backbone by lifting spatial and photometric attributes into unified $3 \times 3$ matrix channels. To align capacity with the underlying 3D carrier, we use a hidden width of $C / 3$ . This design reduces trainable parameters in practice by about 2.4–2.6× across the reported settings (Appendix Table 4), because matrix-valued channels are mixed along the channel axis rather than treated as nine independent scalar channels. At the same time, the matrix contractions and invariant bilinear operations increase GMACs, so we describe the method as parameter-eficient rather than broadly runtime-eficient.

Object Vision: Gaussian-MAE. To assess object recognition from 3D Gaussian splats, we evaluate our E3DGS-MAE architecture using the ShapeSplat dataset and evaluation protocol [28]. By training our equivariant transformer backbone under this established pretraining–fine-tuning setup, we isolate the contributions of available SH degrees $( \ell \leq 0 , 1 , 2 )$ and measure (i) robustness to coordinate frame shifts and (ii) label eficiency in low-data regimes.

## 5.2 Object Recognition on ModelNet40

We include ModelNet40 to test whether the proposed unified representation remains efective when the category space becomes larger and the object geometry is more diverse. All ModelNet40 experiments use the same pretraining and finetuning protocol as our ModelNet10 experiments (Section 5.1).

Table 2 reports accuracy under canonical and transformed evaluation. The main observation is that canonical accuracy alone does not determine pose robustness: a non-equivariant model can remain competitive on <sup>ID/ID</sup> while degrading sharply under transformed evaluation, indicating reliance on pose-specific information. By contrast, E3DGS maintains stable performance across all evaluated splits, consistent with the symmetry built into the active feature stream and the invariant classifier.

Interpretation of SH utilization. Introducing higher-order SH coeficients, as in SH(0, 1) and SH(0, 1, 2), does not degrade the proposed equivariant representation on ModelNet40. In fact, the SH(0, 1) variant achieves the best performance among the E3DGS configurations, reaching 93.17% on all three evaluation splits. The SH(0, 1, 2) variant also improves over SH(0) in the canonical setting (92.57% vs. 92.25%) while maintaining strong pose consistency.

Implication. The main takeaway from ModelNet40 is not only the improved canonical accuracy, but also the ability to maintain performance across transformed splits without relying on posespecific cues. This is precisely the regime in which naive feature-space concatenation becomes restrictive: higher-order SH coeficients carry transformation-sensitive information, and handling them without an explicit equivariant structure leads to poor robustness once the test-time pose varies. The current ModelNet40 results therefore strongly support the claim that the benefit of the unified carrier lies in the pose-consistent learning of Gaussian geometry and appearance.

## 5.3 Action-Conditioned Gaussian World Modeling on ManiGaussian

While Section 5.1 demonstrates the eficacy of our gl(3) carrier for object perception, sequential action in robotic manipulation introduces the challenge of modeling environmental dynamics. Here, we evaluate whether our unified geometric–photometric representation improves predictive world modeling. We instantiate our equivariant Gaussian world model within the ManiGaussian [26] framework and evaluate it on the RLBench multi-task benchmark.

Equivariant Action-Conditioned World Model in the Lifted Space. Given that the Gaussian world state $\mathcal { G } _ { t }$ is lifted into equivariant matrix channels $H _ { t } ^ { \mathrm { s t a t e } }$ , we embed the manipulation action into the same algebraic space to preserve symmetry. Manipulation action $a _ { t } = ( v _ { t } , q _ { t } , c _ { t } )$ comprises a 3D translation $\boldsymbol { v } _ { t } \in \mathbb { R } ^ { 3 }$ , a rotation quaternion $q _ { t }$ , and an invariant gripper openness $c _ { t } \in \mathbb { R }$ . We convert $q _ { t }$ to an axis-angle vector $\omega _ { t } \in \mathbb { R } ^ { 3 }$ . Actions are expressed in the scene/world frame; under a global rotation of the scene frame, both the translational command $v _ { t }$ and the axis-angle vector $\omega _ { t }$ transform as $v _ { t } \mapsto R v _ { t }$ and $\omega _ { t } \mapsto R \omega _ { t }$ . Because both $v _ { t }$ and $\omega _ { t }$ transform as standard vectors $( x \mapsto R x )$ , we use the hat map to lift them into so(3) matrices: $H _ { t } ^ { \mathrm { a c t } } = [ \widehat { v } _ { t } , \widehat { \omega } _ { t } ]$ Since $\widehat { R x } = R \widehat { x } R ^ { \top }$ , these lifted channels natively transform via adjoint conjugation. We concatenate the state and action matrices to form a joint equivariant input. The world model $f _ { \mathrm { w m } } ^ { \mathrm { e q } }$ processes the concatenated state and action matrices, modulated by the invariant gripper state $c _ { t } .$ , to predict the state deformation matrix $\Delta H _ { t + 1 } .$

## 6 Conclusion

We presented E3DGS, a framework introducing rigid-body (SE(3)) equivariance to 3D Gaussian Splatting. At its core is the Unified Matrix Lifting, which jointly embeds spatial geometry and view-dependent photometry into a single gl(3) carrier. By identifying an isomorphism between Spherical Harmonics $( \ell \leq 2 )$ and matrix conjugation, E3DGS bypasses expensive tensor products, enabling eficient, matrix-native equivariant learning. We validated this formulation via a Gaussian Masked Autoencoder for object recognition and an action-conditioned world model for robotic manipulation. Our results confirm that symmetry-consistent 3DGS learning yields exceptional zero-shot pose robustness, label eficiency, and spatial reasoning.

Scope and outlook. Our gl(3) formulation is mathematically bounded to SH degrees $\ell \leq 2$ Although the original 3DGS setting often uses up to degree 3, SH(0–2) captures a substantial photometric subspace and is the maximal bandwidth admitted by the lightweight physical 3 × 3 carrier. Higher bands can be handled by the larger carriers described in Theorem 2, but we leave their empirical evaluation to future work.

## A Explicit gl(3) Intertwiners for SH Degrees $\ell \leq 2$

We provide an explicit realization of real spherical harmonics of degrees $\ell = 0 , 1 , 2$ inside the $3 \times 3$ matrix carrier gl(3). Throughout, $R \in \mathrm { S O ( 3 ) }$ acts on ${ \mathfrak { g l } } ( 3 )$ by conjugation, $\mathrm { A d } _ { R } ( M ) : = R M R ^ { \top }$

Under this action,

$$
\mathfrak {g l} (3) = \langle I \rangle \oplus \mathfrak {s o} (3) \oplus \operatorname{Sym} _ {0} (3),\tag{13}
$$

where $\langle I \rangle = \{ s I : s \in \mathbb { R } \} , { \mathfrak { s o } } ( 3 ) = \{ A : A ^ { \top } = - A \}$ , and $\mathrm { S y m } _ { 0 } ( 3 ) = \{ S : S ^ { \top } = S , ~ \operatorname { t r } ( S ) = 0 \}$

## A.1 Degree $\ell = 0$

For $f _ { 0 } \in \mathbb { R }$ , define

Since $D ^ { 0 } ( R ) = 1$ and $\mathrm { A d } _ { R } ( I ) = I$ , this is an SO(3)-equivariant map.

## A.2 Degree $\ell = 1$

Using $[ R v ] _ { \times } = R [ v ] _ { \times } R ^ { \top }$ for all $v \in \mathbb { R } ^ { 3 }$ , we obtain

## B Exact Capacity of the $3 \times 3$ Carrier and Its Alignment with SH(0–2)

Let $V _ { 1 } = \mathbb { R } ^ { 3 }$ denote the standard irreducible representation of $\mathrm { S O ( 3 ) }$ . Under the conjugation action, the space of $3 \times 3$ matrices is identified with the endomorphism ring:

$$
\operatorname{End} (V _ {1}) \cong V _ {1} \otimes V _ {1}.\tag{32}
$$

By the Clebsch–Gordan decomposition, this tensor product decomposes into irreducible subrepresentations as:

$$
V _ {1} \otimes V _ {1} \cong V _ {0} \oplus V _ {1} \oplus V _ {2}.\tag{33}
$$

Therefore, the $3 \times 3$ conjugation carrier realizes exactly the irreducible types corresponding to spherical harmonics of degrees $\ell = 0 , 1 , 2$ . Notably, no $V _ { 3 }$ component appears in this decomposition. Hence, by Schur’s Lemma, we have:

$$
\mathrm{Hom} _ {\mathrm{SO(3)}} (V _ {3}, \mathrm{End} (\mathbb {R} ^ {3})) = \{0 \},\tag{34}
$$

which formally proves that there exists no non-trivial SO(3)-equivariant linear map from degree-3 spherical harmonics into the $3 \times 3$ conjugation carrier. The $3 \times 3$ carrier covers SH degrees $0 \leq \ell \leq 2 $ ; higher degrees used by practical 3DGS systems are handled by the larger carriers of Theorem 2.

## C General Matrix Carrier for Arbitrary SH Degrees

We show that the $3 \times 3$ instantiation used in the main paper is the minimal case of a general construction: for any finite SH degree, the Wigner-D action is realizable exactly as matrix conjugation on a suitable carrier End(V ). This establishes that the SH(0–2) scope is a property of the minimal carrier, not of the adjoint-matrix principle (Theorem 2).

Setup. Let $V _ { \ell }$ denote the real degree-ℓ irreducible representation of $\mathrm { S O ( 3 ) }$ (equivalently, degree-ℓ real SH coeficients), dim $V _ { \ell } = 2 \ell + 1$ , transforming as $c _ { \ell } \mapsto D ^ { \ell } ( R ) c _ { \ell }$ . In a real orthonormal SH basis $D ^ { j } ( R )$ is orthogonal, hence $V _ { j } ^ { * } \simeq V _ { j }$ and

$$
\operatorname{End} (V _ {k}) \simeq V _ {k} \otimes V _ {k} ^ {*} \simeq V _ {k} \otimes V _ {k} \simeq \bigoplus_ {\ell = 0} ^ {2 k} V _ {\ell},\tag{35}
$$

by the Clebsch–Gordan rule $V _ { j _ { 1 } } \otimes V _ { j _ { 2 } } \simeq \bigoplus _ { \ell = | j _ { 1 } - j _ { 2 } | } ^ { j _ { 1 } + j _ { 2 } } V _ { \ell } \left[ 4 5 , 1 1 \right]$ . The carrier used in this paper is $k = 1$ End $( V _ { 1 } ) \simeq { \mathfrak { g l } } ( 3 ) \simeq V _ { 0 } \oplus V _ { 1 } \oplus V _ { 2 }$ , with the conjugation action $M \mapsto D ^ { 1 } ( R ) M D ^ { 1 } ( R ) ^ { \top } = R M R ^ { \top }$

Equivariant injection for any degree. By (35), for any finite SH degree L choosing $k \geq$ $\lceil L / 2 \rceil$ makes $V _ { L }$ appear in End $( V _ { k } )$ . Concretely, one selects an irreducible tensor-operator basis $\{ T _ { m } ^ { ( \ell , k ) } \} _ { m = - \ell } ^ { \ell } \subset \mathrm { E n d } ( V _ { k } )$ satisfying the standard transformation rule [45, 11]

$$
D ^ {k} (R) T _ {m} ^ {(\ell , k)} D ^ {k} (R) ^ {- 1} = \sum_ {m ^ {\prime} = - \ell} ^ {\ell} T _ {m ^ {\prime}} ^ {(\ell , k)} D _ {m ^ {\prime} m} ^ {\ell} (R),\tag{36}
$$

which defines an equivariant injection $\begin{array} { r } { \iota _ { \ell } : V _ { \ell } \to \operatorname { E n d } ( V _ { k } ) , \iota _ { \ell } ( c ) = \sum _ { m } c _ { m } T _ { m } ^ { ( \ell , k ) } } \end{array}$ . A direct computation then gives the intertwining property

$$
D ^ {k} (R) \iota_ {\ell} (c) D ^ {k} (R) ^ {- 1} = \sum_ {m, m ^ {\prime}} c _ {m} T _ {m ^ {\prime}} ^ {(\ell , k)} D _ {m ^ {\prime} m} ^ {\ell} (R) = \iota_ {\ell} \bigl (D ^ {\ell} (R) c \bigr),\tag{37}
$$

i.e. the $\mathrm { W i g n e r } – D ^ { \ell }$ action is realized exactly as conjugation on the matrix carrier. This proves Theorem 2.

Example: SH3. $V _ { 3 }$ is absent from $\operatorname { E n d } ( V _ { 1 } ) \simeq { \mathfrak { g l } } ( 3 )$ , but

$$
\operatorname{End} \left(V _ {2}\right) \simeq V _ {2} \otimes V _ {2} \simeq V _ {0} \oplus V _ {1} \oplus V _ {2} \oplus V _ {3} \oplus V _ {4},\tag{38}
$$

so $V _ { 3 }$ appears with multiplicity one; the Clebsch–Gordan change of basis yields an equivariant inclusion $\Phi _ { 3 } : V _ { 3 } \hookrightarrow \mathrm { E n d } ( V _ { 2 } )$ , unique up to scale, with $\Phi _ { 3 } ( D ^ { 3 } ( R ) f _ { 3 } ) = D ^ { 2 } ( R ) \Phi _ { 3 } ( f _ { 3 } ) D ^ { 2 } ( R ) ^ { - 1 }$ . Thus SH3 is exactly represented by conjugation in $\mathrm { ~ a ~ 5 ~ } \times \mathrm { ~ 5 ~ }$ carrier $D ^ { 2 } ( R )$ rather than the physical $3 \times 3$ carrier R. In general SH degrees up to $L$ are handled by $\operatorname { E n d } ( V _ { \lceil L / 2 \rceil } )$

Numerical verification. We solved the infinitesimal intertwiner equations as a sanity check. For $X \in { \mathfrak { s o } } ( 3 )$ the induced action on $\operatorname { E n d } ( V _ { k } )$ is $\rho _ { \mathrm { E n d } ( V _ { k } ) } ( X ) M = \rho _ { V _ { k } } ( X ) M - M \rho _ { V _ { k } } ( X )$ , and an intertwiner $\Phi : V _ { 3 } \to \operatorname { E n d } ( V _ { k } )$ must satisfy $\rho _ { \mathrm { E n d } ( V _ { k } ) } ( X ) \Phi = \Phi \rho _ { V _ { 3 } } ( X )$ . Solving these linear constraints gives

$$
\dim \operatorname{Hom} _ {\mathrm{SO} (3)} (V _ {3}, \operatorname{End} (V _ {1})) = 0, \quad \dim \operatorname{Hom} _ {\mathrm{SO} (3)} (V _ {3}, \operatorname{End} (V _ {2})) = 1.\tag{39}
$$

The resulting $V _ { 3 }  \operatorname { E n d } ( V _ { 2 } )$ map has rank $^ { 7 , }$ and a finite-rotation test yields relative equivariance error $1 . 6 8 \times 1 0 ^ { - 1 5 }$ , numerically confirming that SH3 is impossible in the $3 \times 3$ carrier but exact in the $5 \times 5$ adjoint carrier.

## D Unified Lifting and Symmetry Properties

## D.1 Primitive parameterization and centered coordinates

We parameterize a 3D Gaussian primitive as

$$
\mathcal {G} _ {i} = \Big (\mu_ {i}, \Sigma_ {i}, \alpha_ {i}, \{f _ {i, \ell} ^ {(c)} \} _ {\ell = 0} ^ {2, c \in \{r, g, b \}} \Big),\tag{40}
$$

where $\mu _ { i } \in \mathbb { R } ^ { 3 } , \Sigma _ { i } \in \mathrm { S P D } ( 3 ) , \alpha _ { i } \in \mathbb { R }$ , and $f _ { i , \ell } ^ { ( c ) } \in \mathbb { R } ^ { 2 \ell + 1 }$ denotes the real SH coeficients of degree ℓ for color channel c.

For recognition tasks, global translations are removed by centering:

$$
\bar {\mu} _ {i} := \mu_ {i} - \frac {1}{N} \sum_ {j = 1} ^ {N} \mu_ {j}.\tag{41}
$$

Under a rigid motion $( R , t ) \in \mathrm { S E } ( 3 )$ , the centered means satisfy $\bar { \mu } _ { i } \mapsto R \bar { \mu } _ { i }$ , so the active channels become homogeneous under the rotational part.

## D.2 Geometry lift

Position. We lift the centered position via the hat map,

$$
P _ {i} := [ \bar {\mu} _ {i} ] _ {\times} \in \mathfrak {s o} (3),\tag{42}
$$

which satisfies

$$
[ R \bar {\mu} _ {i} ] _ {\times} = R [ \bar {\mu} _ {i} ] _ {\times} R ^ {\top}.\tag{43}
$$

Covariance. We lift the covariance through the matrix logarithm,

$$
C _ {i} := \log (\Sigma_ {i}) \in \operatorname{Sym} (3) \subset \mathfrak {g l} (3).\tag{44}
$$

Since the matrix logarithm commutes with orthogonal congruence,

$$
\log (R \Sigma_ {i} R ^ {\top}) = R \log (\Sigma_ {i}) R ^ {\top}.\tag{45}
$$

This preserves exact SO(3) equivariance while mapping SPD(3) to the linear space Sym(3).

## D.3 Photometry lift

For each color channel $c \in \{ r , g , b \}$ , define

$$
S _ {i} ^ {(c)} := \Phi_ {\leq 2} \left(f _ {i, \leq 2} ^ {(c)}\right) \in \mathfrak {g l} (3), \quad f _ {i, \leq 2} ^ {(c)} := \left(f _ {i, 0} ^ {(c)}, f _ {i, 1} ^ {(c)}, f _ {i, 2} ^ {(c)}\right).\tag{46}
$$

By (31), each photometric matrix channel transforms by the same conjugation law as the geometric channels.

## D.4 Equivariant and invariant feature streams

We collect the active matrix-valued channels as

$$
H _ {i} := \left[ P _ {i}, C _ {i}, S _ {i} ^ {(r)}, S _ {i} ^ {(g)}, S _ {i} ^ {(b)} \right] \in \mathfrak {g l} (3) ^ {C _ {\mathrm{eq}}}.\tag{47}
$$

Alongside them, we maintain a separate invariant scalar stream

$$
s _ {i} := \left[ \alpha_ {i}, f _ {i, 0} ^ {(r)}, f _ {i, 0} ^ {(g)}, f _ {i, 0} ^ {(b)}, E _ {\mathrm{task}} \right] ^ {\top} \in \mathbb {R} ^ {C _ {0}}.\tag{48}
$$

The degree-0 appearance coeficients are intentionally duplicated in the scalar branch: although they are already represented inside the photometric lift through $\Phi _ { 0 }$ , the explicit scalar copy gives the network direct invariant access for gating and readout.

Proposition 2 (Equivariance of the lifted representation). For any $R \in \mathrm { S O ( 3 ) }$ , each active channel of $H _ { i }$ transforms as

$$
(H _ {i}) _ {k} \mapsto \mathrm{Ad} _ {R} \big ((H _ {i}) _ {k} \big) = R (H _ {i}) _ {k} R ^ {\top},
$$

while $s _ { i }$ is invariant.

Proof. The claim follows from (43), (45), and (31).

## D.5 Equivariant processing on the unified carrier

Let $\tilde { B } : { \mathfrak { g l } } ( 3 ) \times { \mathfrak { g l } } ( 3 ) \to \mathbb { R }$ denote the modified Killing form

$$
\tilde {B} (X, Y) := 6 \operatorname{tr} (X Y) - \operatorname{tr} (X) \operatorname{tr} (Y).\tag{49}
$$

This bilinear form is invariant under conjugation:

$$
\tilde {B} (\mathrm{Ad} _ {R} X, \mathrm{Ad} _ {R} Y) = \tilde {B} (X, Y).
$$

The E3DGS backbone is built from Ad-equivariant channel mixing, invariant-gated nonlinearities, ReLN-Attention, and ReLN-LayerNorm. Since each primitive commutes with the channel-wise conjugation action and all gating quantities are built from $\mathrm { S O ( 3 ) }$ -invariant scalars, the backbone preserves exact $\mathrm { S O ( 3 ) }$ equivariance on the active channels.

Theorem 4 (Equivariance of the lifted encoder). Let $\mathcal { F } _ { \theta } ( H , s ) = ( H ^ { \prime } , s ^ { \prime } )$ be any encoder composed of Ad-equivariant matrix operations together with invariant scalar modulation. Then

$$
\mathcal {F} _ {\theta} (\mathrm{Ad} _ {R} (H), s) = \left(\mathrm{Ad} _ {R} (H ^ {\prime}), s ^ {\prime}\right) \quad \forall R \in \mathrm{SO} (3),\tag{50}
$$

where $\operatorname { A d } _ { R }$ acts channel-wise on the active matrix stream.

Translation handling. The exact homogeneous action in the lifted carrier is with respect to the rotational part. For recognition, centering (41) yields global translation invariance. For dynamics, translational quantities are handled through centered or relative vector features before hat lifting, so that the active channels again obey a homogeneous SO(3) action.

## D.6 Task-specific readouts

Invariant readout for recognition. For classification, the final matrix-valued features are converted to invariant scalars by B<sup>˜</sup>-based contractions, concatenated with the invariant branch, pooled across the set, and passed to an MLP classifier. This readout is pose-invariant by construction.

Equivariant readout for dynamics. For vector-valued predictions, the output matrix channel is projected onto so(3) and mapped back to $\mathbb { R } ^ { 3 }$ by the inverse hat map:

$$
v _ {i} = \left(\operatorname{skew} \bigl ((H _ {\text { out }}) _ {\text { pos }} \bigr)\right) ^ {\vee}, \qquad \operatorname{skew} (A) := \frac {1}{2} (A - A ^ {\top}).\tag{51}
$$

Because both skew and $( \cdot ) ^ { \vee }$ commute with orthogonal conjugation, this readout is exactly SO(3) equivariant.

## E Active and Passive Rotation Viewpoints

Under an active rotation of the scene, view directions transform as $d \mapsto R d .$ inducing

$$
f _ {i, \ell} ^ {(c)} \mapsto D ^ {\ell} (R) f _ {i, \ell} ^ {(c)}.\tag{52}
$$

Under a passive change of camera coordinates, directions transform as $d \mapsto R ^ { \top } d .$ inducing

$$
f _ {i, \ell} ^ {(c)} \mapsto D ^ {\ell} (R ^ {\top}) f _ {i, \ell} ^ {(c)}.\tag{53}
$$

In a orthonormal SH basis, $D ^ { \ell } ( R )$ is orthogonal, so $D ^ { \ell } ( R ^ { \top } ) = D ^ { \ell } ( R ) ^ { - 1 }$ . Our matrix carrier accommodates either convention: the lifted channels transform by conjugation with the corresponding rotation argument.

## F Implementation Details for Gaussian Perception Tasks

This section summarizes the implementation details for the Gaussian perception tasks. We focus on the components that are specific to the proposed formulation: rigid-motion-aware input handling, SH(0–2) lifting, the unified matrix carrier, and the task heads used for classification and segmentation.

## F.1 Recognition backbone and feature construction

Starting from Gaussian-MAE, we replace the original Euclidean feature handling with a twostream representation consisting of: (i) an active matrix stream carrying geometry and higherorder photometry, and (ii) an invariant scalar stream carrying opacity, SH0, and auxiliary scalar information.

Each input Gaussian uses SH coeficients up to degree 2 for every color channel unless otherwise noted. Accordingly, the active photometric stream contains the lifted degree-1 and degree-2 appearance content. Local grouping, token mixing, and aggregation are performed directly on matrix-valued channels. The scalar stream interacts with the matrix stream through invariant contractions and scalar gating, so the prescribed transformation law of the active channels is preserved throughout the encoder.

## F.2 Task heads

Classification head. For object classification, the final matrix features are converted to invariant scalar descriptors using B<sup>˜</sup>-based self-contractions and aggregated across tokens by permutationinvariant global pooling. The pooled invariant descriptor is then passed to a standard MLP classifier. We do not use a learnable [CLS] token, since the prediction is intended to depend only on invariant summaries of the lifted set representation.

Segmentation head. For part segmentation, we replace the Gaussian token encoder and backbone. The ReLN encoder and transformer produce matrix-valued group features, which are converted to invariant token descriptors through Killing-form self-contractions. These invariant group features are then propagated to point-level features by the standard feature-propagation module and decoded by a point-wise classifier for part labeling.

## F.3 Datasets and Protocol

To evaluate representation quality, we employ a two-phase learning stage: large-scale unsupervised pretraining followed by task-specific finetuning [28].

Pretraining: ShapeSplat. We utilize the ShapeSplat dataset [28], a repository of ShapeNetderived 3D Gaussian assets. For each 3D object, N = 1024 primitives are extracted using furthest point sampling. The model is trained to reconstruct these primitives under a 60% random masking ratio.

Downstream evaluation on ModelNet10, ModelNet40, and ShapeNet Part. The pretrained encoder is finetuned for object classification on ModelNet10 and ModelNet40, and for part segmentation on ShapeNet Part. We keep the transfer configuration fixed across methods so that diferences in performance can be attributed to the representation rather than to changes in the optimization setup.

We further evaluate the proposed representation on ShapeNet Part Segmentation to assess its efect on dense geometric prediction. Efect of higher-order photometry on segmentation. By contrast, E3DGS maintains nearly unchanged performance across transformed evaluation and does not exhibit the same degradation in the SH(0, 1, 2) setting. ## H Action-Conditioned Gaussian World Modeling

We instantiate the manipulation experiments within the ManiGaussian protocol and retain its training and evaluation setup wherever possible. Our modification is focused on the Gaussian state representation and the dynamics module, which are replaced by their equivariant counterparts in the unified matrix carrier.

## H.1 Pipeline Instantiation

Following ManiGaussian, the manipulation pipeline consists of two coupled parts: (i) a Gaussian world model that predicts the next-step scene from the current observation and robot action, and (ii) a PerceiverIO-based action decoder that predicts the end-efector action from scene features and the language instruction. In the baseline formulation, the world model comprises a representation network $q _ { \phi } .$ a Gaussian regressor $g _ { \phi }$ , a deformation predictor $p _ { \phi }$ , and a Gaussian renderer R; the action decoder then operates on the learned scene representation together with the instruction embedding. In our adaptation, we preserve this overall decomposition. The key diference is that the Gaussian state is first lifted into the unified ${ \mathfrak { g l } } ( 3 )$ carrier, and the state-transition module is replaced with our equivariant dynamics model in the lifted space. The resulting equivariant features are converted to invariant token features before being passed to the PerceiverIO action head, so that the downstream action interface remains aligned with the ManiGaussian protocol.

## H.2 Training objectives

We follow the ManiGaussian training design and optimize a weighted sum of action prediction, current-scene reconstruction, future-scene consistency, and semantic distillation losses:

$$
\mathcal {L} = \mathcal {L} _ {\mathrm{Act}} + \lambda_ {\mathrm{Geo}} \mathcal {L} _ {\mathrm{Geo}} + \lambda_ {\mathrm{Sem}} \mathcal {L} _ {\mathrm{Sem}} + \lambda_ {\mathrm{Dyna}} \mathcal {L} _ {\mathrm{Dyna}}.\tag{57}
$$

Here, ${ \mathcal { L } } _ { \mathrm { { A c t } } }$ denotes the behavior-cloning loss on discretized translation, rotation, gripper openness, and collision-avoidance outputs. $\mathcal { L } _ { \mathrm { G e o } }$ supervises reconstruction of the current scene from the predicted Gaussian state, and $\mathcal { L } _ { \mathrm { D y n a } }$ supervises reconstruction of the future scene conditioned on the current observation and robot action. When semantic supervision is used, $\mathcal { L } _ { \mathrm { S e m } }$ matches the projected semantic features of the Gaussian representation to the corresponding foundation-model features.

Relative to the baseline, the loss definitions themselves are unchanged. The modification lies in how the latent Gaussian state and its action-conditioned transition are parameterized: the transition is predicted in the lifted equivariant space and then decoded back to the Gaussian state used for rendering and downstream action prediction.

## H.3 Dataset and Optimization Setup

We use the same RLBench evaluation protocol as ManiGaussian: 10 language-conditioned manipulation tasks with 166 total task variations. Visual observations are single-front RGB-D images of resolution $1 2 8 \times 1 2 8$ . For multiview supervision of the Gaussian world model, we use the sam number of camera views as the baseline. For a controlled comparison, we keep the optimization recipe unchanged. We use the same PerceiverIO variant as the action decoder, one RTX 4090 GPU, 100k training iterations, batch size 1, the LAMB optimizer with initial learning rate $5 \times 1 0 ^ { - 4 }$ , and a cosine schedule with warmup.
